# Skill behavior evaluation

Contributor-only scenarios for detecting unintended creative bias. These checks are not a required production reading path and do not establish film quality.

## Skill 自身的行为验证

修改本 Skill 时，可用这些差异明显的请求做方案级检查。它们用于发现模板偏置，不能代替成片评测：

- 无旁白的克制品牌片，允许长镜头与静止。
- 准确展示真实软件操作，界面文字必须可读。
- 纯文字、声音驱动的短片，不使用 UI 或容器。
- 固定坐标轴的数据解释，精确数值优先。
- 只调整已有视频的一个接点，不能重做其余内容。

检查是否遵守各自目标、选择性填写字段、保留不同表达方式且不扩张范围。验证实际效果时，使用相同资料与环境比较旧／新流程，保留生成波动、失败与成本记录；单次模型自评不能证明稳定提升。
