主角是一个蓝发、白外套、浅蓝短裤的 3D 动漫风少女，全片在做跑、跳、踢、翻、落地等动作。背景元素有四类：超大粗体字（NEON、单个字母、数字 02）、取景框式 HUD（四角括号、十字准星、条形码、刻度尺）、透视线网与速度线、圆环。每个镜头换一个角度或空间，角色始终是焦点。

## 只用冰白、钴蓝、黑三色

- 白 #f9fafb 与浅冰蓝 约 #bfe4f5 作亮底。
- 钴蓝 约 #2a3ae0 与淡紫蓝 #7f94f0 做圆环、斜切块、强调线。
- 黑 约 #0a0a12 做暗底与大字描边。
- 收尾画面直接写出色板名「ICE / COBALT / WHITE」。

## 文字层级：超大字 > 编号 > HUD 小字

- 最大：「NEON」，超粗无衬线大写，黑或白，带描边或立体厚度。
- 次大：单字母 B、A，以及灰色巨大数字「02」。
- 小号：等宽 / 无衬线大写 HUD 标注（SEQ.01 // NEON-REVEAL // 60FPS、60FPS // VELOCITY LOCK、ROT // 180°、NEON // SLIDE-02、NEON // SERIES 01 // 60FPS、ICE / COBALT / WHITE），配条形码和刻度。

## 节奏：约 2s 一切，动作衔接切点

每个镜头约 2s，切点落在角色动作的转折处（起跳、踢中、落地），黑底与白底交替制造闪烁感。镜头内有快速推拉、旋转（标注 180°）和速度线；结尾放慢，角色站定，主视觉停约 1s。

## 复刻注意

- 素材：需要一个带骨骼动画的 3D 角色（跑、跳、飞踢、翻滚、落地、站立），这是最主要的素材需求。
- `code` 为 true：大字、碎片、线网、HUD、转场都可以用 three.js / HTML 直接重建；角色动作需单独验证，建议使用现成动作数据。
- 难点：字体击碎的碎片物理；角色动作与切点对齐；黑白底快速交替时的可读性。
