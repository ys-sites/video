## 先局部后全景的产品片镜头

前 20 秒全是浅景深特写，每个镜头只给一个物件（电源、标签、火焰、阀门），观众先认识元素；约 24s 起拉到中景和全景，四种颜色同框形成高潮。镜头之间为直切，单镜头内有缓慢推移。

## 近黑桌面只靠火焰和放电管上色

背景与桌面近黑（#161514、#3c3833），金属件为暗黄铜色（约 #8a6a2c）。所有亮色来自燃烧器：橙黄火焰（约 #ff9a2a）、蓝色焰心（约 #2a9cff）、红色放电管（约 #ff2a3a）、紫色放电管（约 #8a6aff）。收尾页切换为高亮蓝渐变（约 #1a5ce0 → #3a8cff），与前面的暗场形成反差。

## 标签是唯一的场内文字

文字只出现在道具上：电源标牌的红底白字警示，胶带上的手写体元素名（Carbon (CH₄)、Neon）。片尾字标为白色无衬线加四角星图标，居中中号。三个元素名正好对应 Gemini 4 的 Carbon / Neon / Argon 三个型号名（观察推断）。

## 内容替换

- 胶带标签可换成任意系列名（产品型号、口味、版本），每个标签对应一种颜色的火焰或光。
- 电源标牌文字、收尾字标可替换。
- 保留「单个特写介绍 → 全部同框 → 品牌页」的结构和暗场单色发光的对比。

## 复刻注意

- 需要：写实 3D 场景（黄铜燃烧器、放电管、电源盒、桌面）、体积火焰模拟、浅景深摄影机。
- 难点：火焰流体模拟和放电管辉光需单独验证质感；微距浅景深和胶带纸张材质影响写实度。
- code 为 true：可用代码化 3D 流程（three.js 着色器火焰或 Blender 脚本）重建；写实度要求高，建议先渲一帧火焰确认。

## 验收要点

1. 前段每个镜头只突出一个物件，背景虚化。
2. 胶带标签上的元素名清晰可读。
3. 全景镜头能同时看到至少四种颜色的火焰 / 放电管。
4. 结尾从暗场直切到亮蓝品牌页。
