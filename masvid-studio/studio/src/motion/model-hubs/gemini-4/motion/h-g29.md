# BEAN TO CUP 等距流程动画

一张等距（斜 45° 俯视）小工坊插画讲完咖啡从豆到杯：镜头沿着生产线依次推近豆仓、烘焙滚筒、冷却盘、磨豆机、浓缩咖啡机，每一站弹出编号标签，最后拉回全景。

## 一张图讲完整个流程

全片只有一个等距场景：米白墙、木黄地板的小房间，生产设备按流程从左上排到右下（豆仓 → 滚筒 → 冷却盘 → 磨豆机 → 咖啡机 → 杯子），设备之间用细管线相连。角落有麻袋、木箱、压力表等细节，还有一个小工人角色。镜头不切换场景，只在这张图上平移和缩放。

## 暖黄木色 + 墨绿与橙两种设备色

- 地板与墙：木黄 #d8c49c、米白 #e7e1d5，墙线与阴影 #927a57。
- 设备：墨绿 约 #1f4a52 机身、橙 约 #d8632a 滚筒与顶盖、奶黄 约 #f0d08a 圆盖、红棕 约 #b0402a 小部件。
- 标签：白底圆角胶囊，红色编号圆点。
- 线条为细深棕描边，整体扁平插画质感。

## 文字层级：标题牌最大，工位标签次之

- 左上标题牌「BEAN TO CUP」：衬线粗体大写，白底黑框。
- 工位标签：小号无衬线大写胶囊「01 BEAN HOPPER」「02 ROASTING DRUM」「03 COOLING TRAY」「04 BURR GRINDER」「05 ESPRESSO BREWER」，出现在当前设备上方。
- 每次只显示当前工位的标签。

## 节奏：一站一推，约 2.5s 一个工位

镜头以平滑推拉沿生产线移动，每到一站停约 2.5s（烘焙段较长，约 5s），标签弹出、设备做一个循环动作（落豆、滚筒转、搅拌、落粉、出咖啡）。没有剪辑，始终是同一镜头的连续运镜。

## 内容替换

- 流程可换成任意线性工序（面包、啤酒、快递分拣、软件部署），保留「一张等距全景 + 逐站推近 + 编号标签」。
- 标题与工位名替换，编号保持 01–05 顺序。
- 设备配色可换，建议保留一种暖色地面和两种对比设备色。

## 复刻注意

- 素材：需要一张分层的等距插画（每台设备单独一层以便做动画）；可用 SVG 绘制。
- `code` 为 true：可用 SVG / CSS 或 Canvas 直接重建，镜头运动用整体 transform 缩放平移。
- 难点：等距插画本身的绘制量大；豆子、咖啡液的小粒子动画需逐站调时序。

## 验收要点

1. 全片只有一个等距场景，镜头不硬切。
2. 依次推近 5 个工位，标签编号 01–05 顺序出现。
3. 每个工位有对应的循环动作。
4. 开头有「BEAN TO CUP」标题牌，结尾拉回全景。
5. 设备之间有管线连接，流程方向清楚。
