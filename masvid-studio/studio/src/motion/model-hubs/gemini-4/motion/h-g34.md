# 圆环机械装置雕塑

一支 10 秒的方形 3D 动效：米白背景上，一座由白色大环、蓝色圆环、白色半球和红蓝小构件组成的机械雕塑在两种形态间变形——「轨道」态各环交错旋转，「建筑」态构件收拢成立柱与平台，再回到轨道态，形成无缝循环。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2.5s | STATE I「HARMONIC ORBITAL」：白环与蓝环倾斜交错，红蓝小圆柱构件散在轨道上，中心白色球体 |
| 约 2.5–4s | 过渡：圆环转正竖立，构件向中心聚拢，球体打开露出橙色核心 |
| 约 4–7.5s | STATE II「ARCHITECTURAL MONOLITH」：中心升起黑白立柱与白色穹顶，蓝色水平环成平台，红蓝板片竖立成围栏 |
| 约 7.5–9s | 过渡：平台环倾斜，板片散开 |
| 约 9–10s | 回到 STATE I 轨道态，与开头衔接 |

## 画面构成：方形画面中央一件装置

装置立在一块黑色圆形底座上，底座外有一圈白色地台和细黑描边圆环，整体占画面约 80%。左上角小字「KINETIC STUDY // 04」带一个颜色小点，左下角「01 STATE I // HARMONIC ORBITAL」或「02 STATE II // ARCHITECTURAL MONOLITH」，右下角「PHASE 023°」这样的相位读数随时间递增到 340°。四角有细线角标。

## 配色：米白底 + 克莱因蓝与珊瑚橙

背景为 #edebe3 暖米白，装置以白色和浅灰（#7f7f96 一带的冷灰阴影）为主体，蓝色圆环接近克莱因蓝，构件和刻度点用珊瑚橙与黑色点缀。三色比例约为白多、蓝中、橙少，橙色只用于小面积强调。

## 节奏：两态往返，相位读数做时钟

全片是一个完整循环：轨道态 → 建筑态 → 轨道态，每次变形约 1.5 秒，稳定态各停留约 2.5～3.5 秒。相机绕装置缓慢旋转，右下相位读数持续增加，给观众一个循环进度的参照。

## 复刻注意

- 素材需求：圆环、球体、立柱、圆柱构件等基础几何体即可，无需外部模型。
- 难点：两种形态间几十个构件的位置 / 旋转插值要逐一编排，循环首尾需要对齐；柔和的环境光与接触阴影需要单独验证。
- `code` 为 true：three.js 用基础几何体和关键帧插值即可直接重建。

## 验收要点

1. 画面为 1:1，装置立在黑色圆底座上居中。
2. 至少两种可辨识的形态：倾斜交错的轨道态与收拢的建筑态。
3. 左下状态标签随形态切换，右下相位读数持续递增。
4. 首尾帧形态接近，可无缝循环。
