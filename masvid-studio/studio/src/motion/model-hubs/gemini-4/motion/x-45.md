## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2s | 俯拍摊开的课本，页面是平面插图：工厂、乌云、山坡和湖泊，旁边一段阿拉伯文正文 |
| 约 2–8s | 插图立体升起成微缩地形块：工厂冒浓烟，乌云下雨，河流穿过树林 |
| 约 8–10s | 相机拉远，模型略收小，烟雾和乌云散开 |
| 约 10–17s | 模型再次放大，乌云飘到上方；书页下方的石刻建筑插图也升起为一座石拱 |
| 约 17–20s | 模型缩回书页，回到平面插图，只剩烟雾残影 |

## 画面构成：书页是舞台，模型从插图位置长出来

画面主体是一本摊开的课本，放在有划痕的深色木桌上，竖版构图让书页占据中部大部分画面。立体模型从原插图的位置升起，呈方块切面的微缩地形（可见土层截面），尺寸约占画面宽度的 80%。书页上的标题、正文、侧栏小机器人插图和底部活动区始终保留，模型浮在其上，书页文字在模型阴影下仍可辨认。

## 配色：暖木色桌面、白色书页、绿蓝模型

背景是 #312419 到 #654d39 的深浅木纹棕；书页为 #e9e5d9 米白与 #c6c7bd 浅灰，栏目标签为蓝色和粉色。模型以草绿、湖蓝和岩石灰为主，工厂深褐，乌云深灰。整体是暖光室内的摄影质感。

## 叙事与节奏：平面 → 立体 → 平面

全片只有一个连续镜头，没有切换。节奏是「插图出现 → 立体升起并演示过程（排烟、成云、降雨） → 补充第二个元素（石拱） → 收回」，演示因果关系的同时始终让观众知道内容来自课本。相机有轻微推拉，视角始终是斜俯拍。

## 内容替换

- 课本页面可换成任何学科内容（水循环、火山、人体器官）；保留「插图原位升起为微缩模型 → 演示过程 → 收回」的结构。
- 页面语言和文字可替换为目标学生的语言。
- 第二个升起元素（石拱）可换成与课文相关的案例物件。

## 复刻注意

- 素材需求：真实或仿真的课本页面图像、木桌背景、对应主题的微缩地形模型。
- 难点：烟雾、云、雨的体积效果与写实书页的光影融合需要单独验证；模型从平面插图「长出来」的过渡是关键。
- `code` 为 true：原帖附提示词，three.js 可重建地形块和粒子烟雨，但写实书页与光照质量要单独验证；也可用 AI 视频生成补足写实质感。

## 验收要点

1. 画面为 9:16 竖版，课本始终在画面中，书页文字可见。
2. 立体模型从原插图位置升起，最后收回平面。
3. 模型中能看到排烟 → 乌云 → 降雨的过程。
4. 全片一个连续镜头，无硬切。
