# 扬克斯巨型机甲踩过纽约

一段 three.js 网页动画的录屏：用 OpenStreetMap 数据搭出的纽约暗色 3D 地图上，扬克斯（Yonkers）的行政区轮廓「站起来」变成发光巨型机甲，依次踩过布朗克斯、曼哈顿、皇后区，最后进入布鲁克林。

## 黑色地图上一个发光巨物，四角是控制面板

主体是由深色多边形块拼成的巨型机甲，轮廓带红色描边，关节处嵌青蓝灯条，胸口一团强烈白光核心。地面是暗色 3D 城市：建筑为细小的立体块，水域为深蓝点阵网格，行政区名以大号字浮在地面上。画面四角为半透明深色面板：左上任务读数，右上镜头与图层控制，底部章节进度条。

## 近黑底 + 红橙描边 + 青蓝发光

- 背景 #01000c，地面与面板深灰 #40484e。
- 机甲描边红 约 #e0302a，关节灯青蓝 约 #3fc8f0，胸口核心白光带暖橙晕。
- 扬克斯起始区块与被踩区域为橙红填充（约 #f08a3a、#e0302a）。
- 地名文字：行政区名白色或浅紫（QUEENS 约 #b090f0），水域名浅蓝（HUDSON RIVER、EAST RIVER）。

## 文字层级：地名最大，面板读数次之

- 地面大字：「YONKERS」「THE BRONX」「QUEENS」「MANHATTAN」「BROOKLYN」，下配小号副名（BOROUGH、NEW YORK COUNTY、LONG ISLAND CITY / ASTORIA）。
- 左上面板：红色小字「SEISMIC TELEMETRY // OSM REL #174494」，章节标题如「RAMPAGE: STOMPING DOWN MANHATTAN」，SECTOR 当前区，三个读数 MEGA-STOMPS、OSM BUILDINGS CRUSHED（随时间增到 3,252）、MECH HEIGHT 3.35 km。
- 右上：CAMERA DIRECTOR（Cinematic、Follow、Street Look-Up、Free Orbit）与 MAP & AUDIO（Theme: Dark OSM、3D Buildings、Roads & Labels、Audio: ON）。
- 底部：五个章节按钮、PAUSE / RESTART、时间 00:19 / 01:00、0.5x / 1x / 2x，以及 OpenStreetMap / CARTO 署名。

## 节奏：五章各一段，镜头跟着脚步走

全片按底部五个章节推进，每章 8–15s。镜头多为低机位仰视机甲（Cinematic 模式），每次落脚都有楼块飞散和冲击圈，读数随之增加。章节之间是连续镜头，靠标题和地名变化提示进度，没有硬切。

## 内容替换

- 地点可换成任意城市：用目标城市的 OSM 行政区边界生成机甲身体，保留「区块立起 → 跨区行走」。
- 章节标题、读数名称、地名都按新城市替换。
- 机甲配色可换，建议保留暗底 + 单一描边色 + 发光核心。

## 复刻注意

- 素材：需要 OpenStreetMap 的行政区边界与建筑数据（需保留 OSM 与底图署名）。
- `code` 为 true：原帖用 three.js 实现，可代码重建。
- 难点：把行政区多边形拆分重组成可行走机甲的变形动画、步行动作与踩踏时的建筑碎块物理都需单独验证；数千栋建筑的渲染性能也要测。

## 验收要点

1. 开场是暗色地图上的橙色起始区块与 OSM 编号标注。
2. 区块立起变成带红描边、青蓝灯条、白光核心的机甲。
3. 至少经过 3 个带大号地名的行政区。
4. 左上读数（踩踏次数、建筑数）随时间增加。
5. 底部五章进度条与时间显示全程可见。
