# 粒子双星黑金轨道变形

一支约 16 秒的粒子变形动画：纯黑背景上，由细密白色粒子组成的球体分裂出一颗橙红发光的球，两球像日食一样部分重叠；随后橙色球的粒子散开绕成光环，形成土星状的环绕结构，环再被拉直成一根横杆，变成「球 + 长杆」的哑铃形，杆体由灰白转成橙红渐变的尾焰，最后一侧膨胀成一团大的半透明粒子球。全片只有粒子在不同几何形态之间流动变形。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 1s | 黑底中央一颗白灰色粒子球，边缘有一圈稍亮的轮廓，球体略偏左 |
| 约 1–3.5s | 球分成两颗：左侧变为橙红发光球，右侧保持白灰球，两球横向部分重叠，交界处粒子混合，形似日食 |
| 约 3.5–5s | 橙色球的粒子向左下散开，拉成一圈倾斜的椭圆光环，白灰球留在中心 |
| 约 5–9s | 土星形态：白灰球外套着一圈倾斜的粒子环，环从灰白逐段染成橙红到金黄；约 8.5s 环左侧开始散成粒子流 |
| 约 9–11s | 环被拉直成一根水平长杆，左端一颗白灰球，形成横置的哑铃 / 球棒形；杆体为灰白色 |
| 约 11–14s | 结构左右翻转：球移到右侧并多出一颗小球，左侧长杆变成由红到黄渐变、向左逐渐变细的发光尾焰 |
| 约 14–15.8s | 尾焰收回，左侧鼓起一团大的半透明橙褐粒子球，与右侧两颗小球连成葫芦形 |

## 画面构成：单个物体居中，四周大面积留黑

画面只有一个粒子物体，始终在中央附近，占画面宽度约 20%～45%，其余全是纯黑 #030303。物体始终保持水平方向展开（左右分裂、环倾斜、杆横置），没有镜头切换，变形本身就是全部内容。粒子密度高，远看像实体，近看边缘有散逸的细粒子。

## 配色：黑底 + 灰白粒子 + 橙红到金黄的发光色

背景 #030303 纯黑，中性粒子为灰白 #c8c8ca 到暗灰 #727274，阴影侧接近 #262627。发光色只有一组暖色渐变：深红 #d8321e → 橙 #f07a1e → 金黄 #f6c23a，发光部分带柔和外辉光。同一时刻通常只有一部分结构发光，其余保持灰白，形成冷暖对比。

## 节奏：每 2～3 秒换一个形态，连续不切镜

形态顺序为「单球 → 双球 → 土星环 → 横杆 → 尾焰 → 葫芦形」，每个形态停留约 2～3 秒，形态之间用粒子散开再聚合的方式过渡，没有硬切。发光色在各形态间转移（从左侧球 → 环 → 尾焰 → 大球），引导视线。

## 细节：粒子质感与光晕

粒子球表面有细微的噪点闪烁，边缘不是硬边，而是向外逐渐稀疏的粒子雾。发光部分外侧有一圈柔和的橙色辉光，灰白部分则几乎不发光。形态切换时，散开的粒子会短暂拖出半透明的尾迹，再被吸回新形状。

## 复刻注意

- 素材需求：无外部素材，全部为程序生成的粒子。
- 难点：数万粒子在球、环、杆、尾焰之间的目标位置插值，以及发光颜色沿结构的分段渐变需要单独验证；粒子数量多时注意渲染性能。
- `code` 为 true：可用 three.js 的 Points 或 GPU 粒子重建，每个形态预先计算一组目标坐标，用插值加噪声扰动完成过渡，辉光用后期 Bloom。

## 验收要点

1. 纯黑背景，主体全部由细密粒子组成，没有实心几何体。
2. 依次出现双球重叠、土星环、横杆哑铃、尾焰、葫芦形五种形态。
3. 发光色为红橙黄渐变，并在不同形态间转移。
4. 形态之间是粒子散开再聚合的连续过渡，无硬切。
