# 卫星产品展示与飞行段落

一支 60 秒的 3D 产品展示片，主角是一颗名为「Helios-X」的金箔包覆卫星：先在浅色摄影棚里转台展示，再切到深色太空背景下展开太阳翼，随后分解出天线、发动机等部件，打开舱板露出内部飞轮，接着离子发动机喷出青蓝色尾焰，切换成粉红色热成像风格的结构视图，最后在深色背景下带尾焰旋转收尾。每段底部有一行英文说明字幕。

## 画面构成：单个产品居中，地面圆环做转台

卫星始终位于画面中心偏上，占画面宽度约 25%～45%，下方一组同心细圆环和刻度线像转台，用来表现旋转角度。背景只有两种：米白摄影棚（有柔和投影）和近黑太空（圆环发青光）。左上角始终有一个极小的青色编号标签。字幕是底部居中的一条黑底白字横条，只在讲解段出现。

## 配色：米白棚景与深空黑两套环境

米白段：背景 #ede9e0，地面圆环与阴影 #bcb9b0。深空段：背景 #070b12 一带，圆环发光 #2fd3e6 青色。卫星本体为金箔 #c9a24a 与深色八角舱体，太阳翼为深蓝 #2a3570。离子尾焰为青蓝 #5fd0ff；热成像段为品红 #d23aa8 与红橙 #f04a3a。

## 文字层级：只有一行讲解字幕

全片唯一可读文字是底部的单行英文字幕，白色小号无衬线字，放在黑色半透明横条上，每段一句，用具体参数讲产品（4.5 kW、61 个实体、4.80 m 太阳翼、265 mN 推力、900 条着色器条纹）。没有标题卡和品牌 logo。

## 叙事与节奏：每段讲一个工程卖点，约 8～12 秒

顺序是「整体外观 → 太阳翼展开 → 部件爆炸视图 → 内部结构 → 推进系统 → 工程视图 → 收尾」。每个卖点配一句字幕和一个专属动作（展开、分离、掀开、喷射、换材质），停留约 8～12 秒。环境在米白与深黑之间切换，米白讲结构，深黑讲运行，切换以硬切为主，开头用一条青色扫描线做揭示。

## 复刻注意

- 素材需求：一个可拆分的 3D 产品模型（含可动部件：太阳翼、天线、舱板、内部飞轮），原片字幕自述模型在 Blender 中建好并实时渲染。
- 难点：爆炸视图的部件分离路径、舱板掀开动画、离子尾焰的粒子 / 着色器条纹、伪色材质切换需要单独验证；需要可用的分件 3D 模型，这是复刻的主要门槛。
- `code` 为 true：可用 three.js 加载 glTF 模型重建，尾焰用粒子或着色器实现，字幕用 HTML 叠加。
