# 森林旅程低多边形动画

## 画面构成：大树干框住主体，镜头多为仰视

森林由粗大的深褐树干和圆团状树冠组成，树干常占据画面两侧，形成竖直的框。机器人由长方体和圆柱拼成，比例厚重，表面无细节纹理，只靠平涂明暗表现体积。特写镜头大量使用（肩头小鸟、眼灯、胸口、水坑），远景与特写交替讲述「苏醒」过程。

## 配色：深青绿森林 + 暖黄光 + 夕阳橙

主色是深青 #1a3a3a、橄榄黄绿 #adb15e、苔绿 #3e563d、黄褐 #8b9154。机器人为深灰绿 #3a4440。高亮色只有两个：眼灯与胸口的柠檬黄 #f2e94a，以及蓝鸟的钴蓝 #2f5fd0。夕阳段转为橙 #f0a040 天空和紫褐 #6a4a6a 云海。红白条纹只出现在机器人背部喷口和螺旋转场。

## 叙事与节奏：慢热苏醒，后段起飞

前 46 秒都在「静 → 醒」，镜头运动很慢，单个镜头停留 5～7 秒；46 秒后进入起飞段，镜头切换加快到 2～4 秒一镜，并出现俯视、鸟瞰和云上飞行。结尾回到地面仰望林冠的空镜，与开头穿林镜头呼应。画面有轻微漂浮的光尘粒子贯穿全片。

## 内容替换

- 机器人可替换为任何「守护者」型角色或产品，保留「林中静立 → 小动物靠近 → 眼睛与核心亮起 → 起飞 → 远去」节奏。
- 蓝色小鸟可换成品牌吉祥物，作为触发苏醒的角色。
- 胸口心形可换成品牌标志，作为唯一的发光图形。
- 结尾空镜可加片名（建议，原片无文字）。

## 复刻注意

- 素材需求：低多边形森林（树干、圆团树冠、草地、水坑）、方块机器人（含眼灯、胸口格栅、背部喷口）、蓝色小鸟、云海。
- 难点：卡通平涂着色与描边、水面涟漪着色器、起飞喷气粒子、红白螺旋转场需要单独验证；镜头路径较多，需逐镜头设计。
- `code` 为 true：可用 three.js 加卡通材质重建，几何体全部由基础形状组成，适合程序化生成森林。

## 验收要点

1. 方块造型深灰机器人静立在圆团树冠森林中，肩上长着小树。
2. 有蓝色小鸟停在机器人肩头的特写。
3. 眼灯由暗变黄，胸口格栅透出黄色心形光。
4. 有水坑同心涟漪、俯视起飞、橙色夕阳云海飞行三个场景。
5. 结尾为林中仰望树冠的空镜。
