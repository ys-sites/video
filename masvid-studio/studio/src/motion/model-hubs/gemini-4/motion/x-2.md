## 前半段用卡片框住「过程」，后半段全屏放「结果」

约 2–21s 的三个阶段都放在同一个版式里：深蓝到亮蓝的渐变底（约 #0a1a5c → #2a6ae0），中间一块圆角画面卡片，底部一行小号白色字幕。约 21s 起卡片撤掉，渲染画面铺满全屏，没有任何字幕。观众先看懂「用了什么参考、怎么建模」，再一次性看到写实成片，前后对比由版式变化直接传达。

## 白模与成片用分屏擦除完成交接

白模阶段整体是浅灰白（约 #d8d8d4），书架、窗格、画架、机械装置只有体积没有颜色。约 20s 画面出现一条竖向分界：左侧已是带木色、铜色和绿罩台灯的渲染，右侧仍是白模，分界向右推移完成切换。复刻时这一刀是全片最关键的信息点，要让同一机位、同一构图下的两种状态严格对齐。

## 配色：灰蓝外景、暗木内景、铜色高光

- 外景：灰蓝天空 #768994、石材米黄（约 #c8b48c）、草坪绿 #495a30，黄昏时有暖橙侧光。
- 内景：深木墙板与书架 #38361f、暖木桌面 #7d6a4c，铜质机械带金黄高光（约 #c89a50），台灯灯罩为饱和绿（约 #2f9a4a），地上铺红色花纹地毯。
- 夜景：深蓝天空（约 #1c2a5a），窗户为暖黄光点，和白天外景形成首尾呼应。

## 镜头节奏：先慢推外景，再在书房里贴近细节

外景段镜头缓慢横移并推向窗户；内景段从门窗格后方穿入，经过全景（画架、书桌、壁炉、书架同框）后转入浅景深特写：表盘、旋钮、成排的转子与铭牌。特写镜头焦点很浅，前景铜件常虚化，形成「档案馆实物」的质感。各镜之间以切换为主，参考图阶段内部是照片拼格逐组替换。

## 复刻注意

- 素材需求：一组真实参考照片（外景、内景各若干）；场景建筑、书房家具、机械装置的 3D 模型；白模与成片两套渲染输出。
- 难点：写实材质（铜、木、玻璃、地毯）与黄昏 / 夜景灯光需要高质量渲染器，建议先单独渲一帧确认质感；机械装置的复杂零件（转子、表盘、飞轮）建模量大，要单独验证。
- 分屏擦除要求白模与成片同机位逐帧对齐，建议两次渲染共用同一相机路径。
- `code` 为 true：采集备注称由多 agent 编写 Blender 场景完成，可用 Blender Python 脚本或 three.js 代码重建场景、相机路径与切换；原工程、材质参数和相机数据未公开。

## 验收要点

1. 前 21s 三个阶段都使用「蓝色渐变底 + 圆角卡片 + 底部一行字幕」，21s 后画面全屏无字幕。
2. 白模到成片之间有一次同机位分屏对比，分界两侧构图完全一致。
3. 外景、书房内景、夜景三种光照都出现，夜景窗户为暖光。
4. 机械装置在冷开场和内景特写中都能辨认出飞轮、表盘和成排转子。
5. 结尾落版居中显示图标与「Gemini 4 Neon」（或替换后的品牌名）。
