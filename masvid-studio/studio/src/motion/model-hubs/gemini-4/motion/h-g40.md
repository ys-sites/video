## 画面构成：角色在上、设备在下的对称构图

章鱼头部位于画面上方中央，两条长触手向左右上方伸展成「V」形，撑满画面宽度；其余触手垂下落在设备上。设备是一台木框调音台：左半是两个银色开盘磁带盘和一块显示「04:20」的小屏，右半是两块黄色 VU 表、推子、旋钮和彩色按键。背景底部有深色海底礁石剪影和几颗气泡。

## 配色：深海蓝底 + 玫红角色 + 彩色按键

背景为 #13243b 深海蓝，带几道斜向的浅蓝光束。章鱼主体为玫红到 #551528 酒红的渐变，触手上有浅粉圆点；耳机是黄色带青色内圈。设备外框为暖棕木色，按键用粉、青、黄、紫、蓝五色，银色磁带盘接近 #998281 的暖灰阴影。

## 节奏：小幅循环动作，无镜头运动

全片相机固定，只有角色和设备在动：触手按节拍抬落、磁带盘匀速旋转、头部左右轻摆、眼睛开合。动作幅度小、周期短（约 1～2 秒一拍），适合做无缝循环的 GIF 或贴纸。

## 内容替换

- 章鱼可换成其他吉祥物角色；保留「角色在上、触手 / 手臂操作设备」的构图和小幅循环动作。
- 调音台可换成键盘、游戏手柄或自家产品界面。
- 屏幕上的「04:20」等小文字可换成品牌信息。

## 复刻注意

- 素材需求：章鱼和调音台的矢量插画分层（头、各条触手、磁带盘、按键）。
- 难点：触手的弯曲动画需要骨骼或路径变形，要单独验证自然度；循环首尾需对齐。
- `code` 为 true：SVG + CSS / JS 动画或 Canvas 可直接重建，触手可用贝塞尔路径参数化摆动。

## 验收要点

1. 角色头部居中偏上，两条长触手左右张开。
2. 磁带盘持续旋转，触手有交替抬落动作。
3. 相机固定，首尾姿势接近，可无缝循环。
4. 配色为深蓝底、玫红角色和彩色按键。
