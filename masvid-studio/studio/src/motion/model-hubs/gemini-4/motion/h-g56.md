# 森林机器人柔光插画叙事

## 画面构成：竖直树干框住中心主体

松树树干在画面两侧竖直排列，像画框把视线集中到中央的机器人。远景、特写交替：远景交代森林与体量，特写（眼睛、胸口、手掌）交代「醒来」的细节。地平线以下有一层贯穿全片的白色低雾。起飞段改用仰视和天空构图，机器人从画面中央缩成一个小点。

## 配色：灰绿森林 + 橙色核心光

主色是墨绿 #2b3433、苔绿 #4c594d、灰绿 #647961，机器人本体为石灰绿 #8a9a80 加铜褐色关节 #8a5a3a。浅雾和天空为 #c4cbb4 一带的浅灰绿，云团是暖米黄 #f2d6a8。唯一的强饱和色是胸口核心与眼睛的橙色 #f08a2a，醒来后成为画面焦点。

## 叙事与节奏：沉睡 → 苏醒 → 起身 → 离开

故事分四拍，每拍用不同景别：远景交代沉睡状态（约 7 秒），连续三个特写表现苏醒（眼、核心、手，约 11 秒），中景表现站起与眼睛点亮（约 8 秒），天空段表现起飞离开（约 8 秒），最后用空镜收尾。镜头运动缓慢，以推近和环绕为主，节奏平稳，靠光的变化（暗 → 亮）推动情绪。

## 内容替换

- 机器人可替换为任何「沉睡后苏醒」的主体（古代石像、巨兽、产品），保留「暗 → 核心点亮 → 起身 → 离开」四拍。
- 胸口核心可换成品牌标志或产品发光部件，作为全片唯一的高饱和色。
- 森林可换成其他环境，建议保留低雾层和竖直元素框住主体的构图。
- 结尾空镜可加片名或品牌名（建议，原片无文字）。

## 复刻注意

- 素材需求：带青苔和小植物的机器人模型（需要可动关节：头、手、腿）、松树林、低雾、云团、鸟群。
- 难点：机器人从跪姿站起的动作、卡通渲染（平涂 + 描边）着色器、核心发光与推进气流粒子需要单独验证；整体是对角色动画和风格化渲染要求较高的一支。
- `code` 为 true：可用 three.js 加卡通着色器重建场景与镜头，角色动作建议用预制骨骼动画。
- 第一帧底部出现网页播放器控制条，说明原片可能是网页实时渲染后录屏，复刻时成片中不需要这条控制条。

## 验收要点

1. 开场机器人跪在雾气森林中，双眼和胸口都是暗的。
2. 有眼睛、胸口核心、手掌三个特写，核心由暗变成橙色发光。
3. 机器人站起后双眼亮橙光，脚底喷出气流升空并穿过云层。
4. 结尾为空荡林地与天上一道白色尾迹。
5. 全片保持灰绿主色，橙色只用于核心和眼睛。
