# 可破坏的体素世界

一个网页 3D 小游戏的录屏：等距视角下一座彩色体素城堡被点击爆破，方块碎屑四散落地，界面实时统计体素与碎屑数量。

- 唯一 ID：x-7
- 原帖：https://x.com/kimmonismus/status/2123168366949245260
- 作者：@kimmonismus
- 生成模型：Gemini 4 Neon
- 尺寸 / 比例：1280×720，16:9
- 时长：约 10.5s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 1.5s | 完整城堡静置，计数 VOXELS 910、DEBRIS CAP 0 / 900、STRIKES 0 |
| 约 1.5–3.5s | 连续点击爆破，城堡正面与顶部方块飞散，碎屑飞向空中 |
| 约 3.5–5s | 碎屑落地铺满场地，计数停在 VOXELS 859、DEBRIS 153 / 900、STRIKES 3 |
| 约 5–10.5s | 镜头保持，城堡残缺状态静置，碎屑逐渐减少（DEBRIS 降到约 142） |

## 一座城堡、一圈围墙，四角 UI 卡片框住场景

主体是居中的体素城堡：深灰石基座、米色砖墙、红橙相间的城垛条带、顶部黄色方块尖顶，中间嵌蓝色拱窗（文案称 cobalt cores）。城堡外是一圈橙红色矮墙围出的方形场地，地面有浅色同心圆纹。画面四角是圆角白卡：左上标题卡、右上统计卡、底部左侧工具栏、右下操作提示。

## 暖沙色调，红橙和钴蓝做点缀

- 背景沙地与天空 #d6cab6、#eee6da，阴影与远景沙丘 #bea586、#a27457。
- 城堡强调色：红 约 #d2452f、橙 约 #e8902f、黄 约 #e8b83a，基座深灰 约 #2f3238，窗内钴蓝 约 #2f6fd6。
- UI 卡片为近白半透明底、深色字，选中按钮为橙红底白字（Blast、Citadel、Collapse），Reset 为黑底白字。

## 文字层级：游戏标题卡最大，其余全是界面小字

- 左上：小号红色「04 · VOXEL DEMOLITION STUDIO」，下面粗体「Terra Breaker」，再下一行小字「Sunlit sandstone monolith arena · shatter arches & cobalt cores」。
- 右上：VOXELS / DEBRIS CAP / CORE（20/20，蓝色）/ STRIKES / CLEARED 进度条。
- 底部：DEMOLITION TOOL（Blast、Chisel、Cannon）、BLAST RADIUS 滑杆 2.8、STRUCTURE（Citadel、Ziggurat、Aqueduct）、ARENA（Collapse、Sound: On、Reset）。
- 右下提示：Click voxel to demolish · Drag to orbit · Scroll zoom · 1–3 tools · R reset。

## 节奏：前半段爆破，后半段停在结果上

镜头全程固定。爆破集中在 1.5–3.5s，方块带旋转飞出并在地面弹跳停住；之后画面基本静止，只有统计数字变化，阅读重点落到「打掉了多少」。没有转场。

## 内容替换

- 标题、副标题、编号可换成任意游戏或产品名，保留左上标题卡格式。
- 结构可换（官方面板里就有 Ziggurat、Aqueduct），保持体素风格和两到三种强调色。
- 配色可整体换成雪地、夜景等主题，保留「浅底 + 高饱和方块」对比。
- 统计项可改成自己的指标，保留右上横向数字条。

## 复刻注意

- 素材：无需外部素材，全部是程序生成的体素。
- 难点：方块破碎的物理（飞散、弹跳、落地停住）和碎屑上限回收需要单独验证；`code` 标记为 false，参考片是交互录屏，复刻成视频时建议写死点击时间点和爆破位置。
- 建议：用 three.js InstancedMesh 承载上千个方块，阴影用一盏平行光即可还原。

## 验收要点

1. 初始城堡完整，四色条带（深灰基座、米色墙、红橙城垛、黄顶）清楚可辨。
2. 1.5–3.5s 内至少 3 次爆破，STRIKES 从 0 增到 3，VOXELS 同步减少。
3. 碎屑有旋转飞散并在地面停住，不穿地。
4. 四角 UI 卡片与文字齐全，选中态按钮为橙红色。
5. 镜头固定，无转场。
