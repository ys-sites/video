# three.js 黑洞视界

一支电影感 three.js 场景片：两个「视界」场景交替——「Aurum」是金橙色吸积盘压在麦田、农舍和皮卡上方，「Viola」是白色光环下的紫色花海和背对镜头的宇航员，中间用黑场切换，四周带细小的观测仪表 HUD。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 3.5s | Aurum：巨大橙色吸积盘斜挂地平线，右下农舍、左下皮卡剪影 |
| 约 3.5–7s | 画面整体压暗到近黑，底部导航从「Aurum」切向「Viola」 |
| 约 7–17s | Viola：白色光环横跨地平线，紫色花海，宇航员背影居中；前景有白色雾团飘过，镜头缓慢后退 |
| 约 17–21s | 切回 Aurum，远景 |
| 约 21–28.1s | Aurum 推近：吸积盘占满画面，镜头低机位推向皮卡与农舍 |

## 两个场景一个构图模板

两个场景都把黑洞放在上半画面、地平线横穿中部、下半是一片植物（麦田 / 花海），主体剪影（农舍 + 皮卡 / 宇航员）压在地平线上。切换时只换颜色和主体，构图不变，观众很快能对比两种「视界」。

## 金橙与紫白两套色

Aurum：近黑天空、吸积盘由白黄到橙（约 #f0b050 → #c86418），地面暗金（约 #5a3a14），农舍窗口暖黄。Viola：灰紫天空（#504356）、白色光环与地平线（#ddcebe）、深紫花海（#251938）点缀金色光点，雾团为暖灰（#a08d8c）。

## HUD 是小字，标题只在左上

左上为场景卡：小号大写「TWO HORIZONS」、衬线标题「Viola」/「Aurum」、一行等宽描述（如「A violet field beneath the arc of the disk」）。左下是等宽遥测数据（ALT、HORIZON、FPS 等），底部居中是场景切换导航「Aurum — Viola」，右侧有细刻度尺。文字全部很小，不抢画面。

## 内容替换

- 两个场景名和描述可换（如 Day / Night、产品两种配色），保留「同构图、换色和主体」的双场景结构。
- 前景主体（农舍、皮卡、宇航员）可换成品牌物件。
- HUD 数据和导航文字可替换。

## 复刻注意

- 需要：three.js 场景、黑洞吸积盘着色器（引力透镜弯曲光环）、大量实例化植物、雾粒子、后期泛光。
- 难点：吸积盘的透镜弯曲与泛光着色器需单独验证；数万株花草实例的性能。
- code 为 true：可用 three.js 代码直接重建，HUD 用 HTML 叠加。

## 验收要点

1. 两个场景构图一致：黑洞在上、地平线居中、植物铺满下半。
2. 场景切换有压暗过渡，底部导航同步高亮当前场景名。
3. 吸积盘呈弯曲光环并有泛光。
4. 结尾段镜头持续推近 Aurum 前景主体。
