# 琉璃孔雀对称展开动画

一支约 22 秒的矢量风格孔雀循环动画：一只青绿色、金边细节的孔雀站在白色圆形展台上，正面开屏成半圆扇形，尾羽上的眼斑依次亮起闪光；随后整面尾屏向中间收拢成一束竖直的窄羽，再重新向两侧展开，最后眼斑从中心向外再次闪光，回到开屏状态。

## 画面构成：中轴对称，主体居中

孔雀严格沿画面竖直中线左右对称，尾屏占画面宽度约 60%，身体、腿和展台在下半部。展台是一个白色带金边的扁圆柱，顶面有浅青色反光。画面左上角有一个深灰半透明标签写模型名，右下角有深灰底白字署名「@leo114119」。背景只有米白渐变，没有其他元素。

## 配色：薄荷青羽毛 + 金色描边 + 米白底

背景为 #ede6dc 米白，向四角略暗。尾羽主色是薄荷青 #78a091 到亮青 #3fd6c6 的渐变，眼斑由外向内为浅金 #e6d49a、青绿、深蓝 #1e3a5f 瞳心。所有羽片和身体都有细金色描边 #c9a24a，身体为深青绿带鳞片纹。展台白色带浅灰阴影 #c3d1c0。闪光时眼斑中心变成接近白色的亮青。

## 动作与节奏：开 → 闪 → 收 → 开 → 闪

全片只有一个主体和两类动作：尾屏开合与眼斑闪光。开屏到收屏约 3 秒，收拢状态停留约 2 秒，再约 2 秒展开，节奏舒缓。闪光以「中心向外」的波纹方式传播，两次闪光分别出现在开头和结尾，使首尾可以无缝循环。

## 细节：头冠、颈部和展台反光

孔雀头部有三根带圆球的冠羽，喙为金色，眼睛是白底深青瞳。颈部由一节节金色环片串成，像首饰的链节；胸腹是一个深青绿椭圆，表面有鳞片纹。腿为金色细杆，脚下展台顶面映出淡青色倒影。

## 复刻注意

- 素材需求：一根尾羽的矢量组件（羽轴 + 羽片 + 三层眼斑），按角度复制约 40 根；孔雀身体、头冠、腿；白色展台。
- 难点：尾羽从扇形收拢成竖束的过程中，羽片会重叠和缩放，需要单独验证排序和层级；闪光波的延时传播需要按羽毛角度计算。
- `code` 为 true：可用 SVG 或 Canvas 直接重建，尾羽用循环生成并按极坐标排列，开合用统一的角度插值驱动。

## 验收要点

1. 孔雀正面站在白色金边展台上，尾屏为左右对称的半圆扇形。
2. 尾羽眼斑有从中心向外传播的闪光，至少出现两次。
3. 中段尾屏收拢成一束竖直窄羽，再展开回半圆。
4. 背景保持米白，羽毛为薄荷青加金色描边，首尾状态一致可循环。
