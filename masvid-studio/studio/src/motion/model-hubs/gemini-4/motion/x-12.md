# 对齐 NASA 数据的太阳系科普

一支交互式 3D 太阳系「Celestial Orrery」的操作实录：从全景依次放大到火星带、木星、土星、天王星，每到一颗行星右侧弹出带 NASA 数据的信息卡，最后缩回全景。

- 唯一 ID：x-12
- 原帖：https://x.com/kimmonismus/status/2123168533303763074
- 作者：@kimmonismus
- 生成模型：Gemini 4 Neon
- 尺寸 / 比例：1280×720（16:9）
- 时长：约 15.84s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2s | 全景：太阳居中，八大行星轨道和名牌标签 |
| 约 2–4s | 镜头推向木星，途经火星与小行星带，右侧弹出 Jupiter 信息卡 |
| 约 4–6s | 木星特写，条纹与卫星可见 |
| 约 6–10s | 切到土星（Saturn），信息卡随之更新 |
| 约 10–12s | 天王星（Uranus）特写，环系倾斜，信息卡更新 |
| 约 12–13.5s | 约一秒黑场 / 过渡（场景重载或镜头拉远中） |
| 约 13.5–15.84s | 回到太阳系全景 |

## 一个固定 UI 外壳，中间换行星

UI 外壳全程不动：左上标题卡「08 · DEEP SPACE OBSERVATORY / Celestial Orrery」，副标题说明非等比；顶部右侧控制条（Pause、Speed 滑杆、Labels、Orbits、Zoom +/-、Overview）；底部是九个天体胶囊（Sun 到 Neptune），当前天体高亮；右下是操作提示。中间 3D 场景每次推近一颗行星，右侧信息卡同步切换。

## 纯黑星空，只有行星有颜色

背景近黑 #020308 加稀疏星点，UI 面板是半透明深灰（约 #1a1c22，描边 #3a393a）。颜色全部来自行星本身：太阳橙（约 #f08a24）、木星橙白条纹、土星米黄（约 #d9c48e）、天王星青绿（约 #8fd0cc）。强调色是控制条和胶囊上的暖黄（约 #e8b04a）与亮蓝按钮。

## 信息卡是文字主层

信息卡结构固定：小号大写「5TH PLANET FROM SUN」→ 粗体行星名「Jupiter」→ 蓝色类型「Gas Giant」→ 右上金色倍数「11.0× Earth」→ 六格数据（MEAN DISTANCE 5.20 AU、MEAN DIAMETER 139,822 km、ORBIT PERIOD 11.86 years 等）→ 一段描述 → 参考来源（NASA Planetary Fact Sheet、JPL SSD）→ Prev / Next / Overview 按钮。

## 内容替换

- 天体可换成任何可排序的对象集合（卫星、星座、产品系列），保留「全景 → 逐个特写 + 信息卡 → 回全景」。
- 信息卡字段和数值、参考来源链接可替换；保持六格数据 + 一段描述的版式。
- 标题卡文字可换成品牌或栏目名。

## 复刻注意

- 需要：three.js 等 3D 场景（行星贴图、环系、轨道线、小行星点云）、HTML UI 层、镜头推拉动画。
- 难点：行星贴图与环系透明度；镜头在行星间平滑飞行的路径。12–13.5s 的黑场是否为原片过渡无法从截帧确认，建议复刻时用连续拉远代替。
- code 为 true：场景与 UI 都可用代码直接重建，数据可取 NASA Planetary Fact Sheet。

## 验收要点

1. 每次聚焦一颗行星时，底部胶囊与右侧信息卡同步切换到同一天体。
2. 信息卡数值与 NASA 公开数据一致，并标出参考来源。
3. UI 外壳全程位置不变，只有中间 3D 场景运动。
4. 开头和结尾都是太阳系全景。
