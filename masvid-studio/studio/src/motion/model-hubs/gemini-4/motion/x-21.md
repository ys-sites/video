## 界面像一套完整的飞行控制台

画面四周叠着半透明磨砂面板，中间留给 3D 机体：
- 左上：三角形徽标、品牌「STRIX」加金色「HX-9」，下面一行小字「COAXIAL COMPOUND GUNSHIP · CONCEPT AIRFRAME」。
- 右上：六个带色点的环境切换胶囊「BOREALIS」「DUNE」「NEON」「TEMPEST」「ECLIPSE」「STRATOS」，旁边一个音量按钮。
- 左侧：「VIEW」面板（Orbit / Chase / Cockpit / Cinema）和「RENDER」面板（Skin / X-Ray / Power flow / Air flow / Exploded）。
- 左下：飞行数据面板，标题随阶段变化（如「LIFT-OFF · HOVER CHECK」「SHUTDOWN · ROTOR BRAKE」），列出 NR、IAS、VS、TGT、ALT、HDG、TQ、FUEL 等数值，并带一个小地平仪。
- 底部中间：模式条「PARKED / BOARDING / COMBAT / CRUISE / STEALTH」，当前项金色下划线；中央圆形金边大按钮显示「LAND」「LAUNCH」或「RESUME」；右侧弹药计数「30MM 1200」「ROCKETS 34」「MISSILE 6」「FLARES 60」，开火后数字减少。

## 配色：暖砂主调，环境决定整体色温

- 主调来自沙漠和云海的暖色：#a0684c、#84553e、#6c3a27，云海亮部偏米白 #ceb49d 和淡紫。
- 环境切换会整体换色：极光段是青绿极光加紫色（约 #30e0a0 / #8040c0），霓虹城市是黑底亮窗加洋红（约 #e030c0），暴雨海面是深蓝（约 #10304a）。
- 机体是米白与灰的哑光涂装，局部有橙色发光格栅；UI 强调色统一为金黄（约 #e0b040），停机坪外圈也是金黄环。

## 镜头与节奏：每个环境停留数秒，演示一种状态

镜头以环绕和跟随为主：停机时缓慢绕机身一圈，飞行时在机体侧后方跟拍，旋翼特写时转到正上方。环境之间是直接切换，没有过渡动画，每个环境停留约 2～8s。开火段曳光弹拖出白色光条，降落段扬尘把画面整体提亮成白雾，作为收尾。没有片尾落版。

## 内容替换

- 机型可换成任意概念载具（飞船、无人机、跑车），保留「停机 → 起飞 → 巡航 → 演示功能 → 降落」的状态顺序。
- 品牌名、型号、副标题与六个环境名可换，保留左上品牌、右上环境胶囊、底部模式条加中央大按钮的界面布局。
- 弹药计数可换成产品参数（电量、续航、载重），保留数字随动作变化。
- 环境可增减，建议至少保留一冷一暖两种色温做对比。

## 复刻注意

- 素材需求：程序化或手工建模的直升机（共轴双旋翼、尾部双涵道推进器、短翼挂架）、六套环境（沙丘、雪林极光、城市楼群、红色山体、海面暴雨、体积云海）、停机坪与经幡。
- 难点：体积云、海浪与雨、极光、扬尘粒子都需要着色器或粒子系统，要逐个单独验证；旋翼运动模糊与透明桨盘需要专门处理；X-Ray、Exploded 等渲染模式在视频中只露出菜单，未见实际效果。
- `code` 为 true：采集备注称机体由 three.js 程序化生成，可用 three.js 代码重建机体、环境切换、界面面板与状态机，再录屏；原工程与着色器参数未公开。

## 验收要点

1. 至少出现四种明显不同色温的环境，且切换时界面面板保持不变。
2. 起飞时出现「LIFT-OFF」提示，降落时左下面板标题变为「SHUTDOWN · ROTOR BRAKE」。
3. 开火段可见曳光拖尾，右下弹药数字随之减少。
4. 俯视旋翼时桨盘外圈有金色细环，旋翼呈透明运动模糊。
5. 结尾直升机落在标有「HX-9」的圆形停机坪上并扬起白色尘雾。
