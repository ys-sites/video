## 每 1.8 秒换一种版式，主角不变

全片约 8 个镜头，每个约 1.5～2 秒，每次换背景色、版式结构（圆、斜切、网格、跑道）和文字排法；骑车鹈鹕始终在画面中心附近，作为贯穿元素。转场多为直切加碎片、色块擦除。

## 米白、红、黑、青绿四色

主色：米白（#e0d9cf）、朱红（#d83924）、深棕黑（#3a221f）、灰米（#c3b6ad），中段加入青绿（约 #2a9a8a）作为背景色块。鹈鹕白身橙嘴，红色自行车和红围巾把角色与红色版式元素连起来。

## 粗体无衬线大字是画面骨架

「NEON」「PELICAN」用超粗无衬线大写，宽度几乎占满画面，有时为描边字、有时为实心字；鹈鹕在字前或从字中穿过，形成前后层次。小号等宽标签（BENCHMARK // 100.0%、PERSPECTIVE GRID、25 DEG）放在角落，模仿技术测试界面。

## 内容替换

- 两个关键词（NEON / PELICAN）可换成品牌名与产品名，保留交替出现的节奏。
- 鹈鹕骑车可换成任何品牌角色加一个动作；红围巾、红车这类同色道具保留，用来串起版式。
- 收尾一群角色排队 + 大字 + 圆章的落版可直接复用。

## 复刻注意

- 需要：扁平矢量角色（骑车循环动作）、多种版式背景、超粗无衬线字体。
- 难点：角色骑车循环动画和叠影需逐帧绘制或骨骼动画；8 种版式切换节奏要紧凑一致。
- code 为 true：版式、文字与图形可用 SVG + HTML/CSS 动画直接重建；角色建议做成分层 SVG 再用代码驱动。底部播放控制条是录屏界面，复刻时可去掉。

## 验收要点

1. 每个镜头约 1.5～2 秒，至少 6 种不同版式。
2. 骑车角色每个镜头都在，红色道具醒目。
3. 品牌词以超粗大字出现至少三次。
4. 结尾为大字 + 一排角色 + 圆章的落版。
