## 画面构成：每屏一个动效原理，像作品集目录

每屏只讲一个动效概念：节奏（倒计时环）、速度（箭头阵）、空间（多面体）、程序化（柱阵）、动力学（弹跳球）、曲线（曲线编辑器）。主体放在画面中心或左半，右侧或四周放极小的等宽参数字，例如「ANGULAR_VEL // 720 DEG/S」「SYNC // 120.0 BPM」「cubic-bezier(0.86, 0.00, 0.12, 1.00)」。右上角始终有一行很小的时间码与「60 FPS」字样，四角有取景框角标，营造监视器界面感。

## 配色：黑底为主，红、荧光绿、电光蓝三色卡点

大部分屏是近黑或深蓝黑底；米白 #f4f1ea、正红约 #e8241f、荧光绿约 #d8f41c 作为整屏底色轮流跳出，形成闪屏感。图形强调色是红、蓝约 #4f5bf0、荧光绿和青色约 #2ee6d6。palette 中 #a8f6ea 对应青色图形，#827170 是灰阶过渡。波浪段每个词换一组底色，是全片颜色变化最快的地方。

## 文字层级：粗体无衬线大字 + 等宽参数小字

主词是粗黑无衬线大写（MOTION、VELOCITY、DYNAMICS、DESIGN），常放在黑色圆角框里或做 RGB 色差错位。中层是白色或荧光绿粗体副标题（PROCEDURAL SYSTEMS、THE GRAPH EDITOR、12 PRINCIPLES…）。底层是等宽小字参数和标签。结尾标题卡用白色大字、四个小胶囊标签、一行灰色说明「AVAILABLE FOR SELECT PROJECTS · REAL-TIME 60 FPS PROCEDURAL RENDER」。

## 转场与节奏：前后快、中间稳

开头 0.6～2 秒内闪过四屏，每屏约 0.3 秒；中段多面体、弹跳球、曲线编辑器各停 1.5～3 秒，让动作看清；9.4 秒后又回到每 0.5 秒一词的快切。转场以硬切和 RGB 色差故障为主，粒子旋涡用作进入结尾卡的过渡。

## 内容替换

- 「MOTION DESIGN」标题卡、胶囊标签和服务标签可替换为个人或团队名称与能力。
- 波浪段的四个词（DESIGN / SYSTEMS / CRAFT / IMPACT）可换成品牌关键词，保留「波浪条纹底 + 黑框白字」形式。
- 等宽参数字可换成真实参数；左上编号标签「01 // …」可改成章节名。
- 每屏的动效概念可替换为产品功能演示，但保留「一屏一个概念、主体居中、四角小字」结构。

## 复刻注意

- 素材需求：无外部素材，全部为文字、矢量图形、简单 3D 多面体和粒子。
- 难点：多面体线框长面、碎裂、再聚合的过程，以及流线粒子旋涡需要单独验证；弹跳球的挤压拉伸要逐帧检查。
- `code` 为 true：可用 HTML/Canvas + three.js 直接重建，曲线编辑器一屏可用 SVG 绘制贝塞尔曲线。
- 全片 60fps，快闪段每屏只有十几帧，导出帧率低于 60 时快闪会丢屏。

## 验收要点

1. 开头米白底「MOTION」大字带色差进场，左上有红色编号标签。
2. 前 2 秒内至少闪过 3 屏不同底色的关键词或图形。
3. 有多面体由线框到碎片再到实心球的变化。
4. 有红白斜分屏的弹跳球屏，底部写「12 PRINCIPLES」。
5. 结尾是带细框的「MOTION DESIGN」标题卡和四个服务标签，四周粒子环绕。
