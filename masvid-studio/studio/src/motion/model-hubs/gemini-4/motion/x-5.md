# 一次会话做出的 17 个 demo 合集

一支 16 秒的快剪合集：每约 2 秒切一个由 Gemini 4 在同一会话里做出的网页 demo，从赛博飞行游戏、弹幕射击、城市夜景到产品配置器和数据看板，展示单次会话能产出的类型跨度。

- 原帖：https://x.com/kimmonismus/status/2123168299890704735
- 作者：@kimmonismus
- 生成模型：Gemini 4 Neon
- 尺寸 / 比例：1280×720，16:9
- 时长：16.0s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2s | 霓虹线框隧道飞行游戏：紫粉网格赛道、青色飞船、左上血条右上分数 001,900 |
| 约 2–4s | 竖版弹幕射击「SOLARIS」：深蓝竖框战场，左侧计分、右侧按键说明面板 |
| 约 4–6s | 峡谷飞行游戏：橙色峡谷中穿越圆环，顶部「04 / 12」关卡计时 |
| 约 6–8s | 城市夜景沙盒：成排亮窗高楼、落日天空，顶部时段切换按钮（Night / Dawn / Noon / Sunset） |
| 约 8–10s | 流体绘画模拟：粉白烟雾在深绿底上流动，左侧参数滑杆面板 |
| 约 10–12s | 耳机配置器「Bespoke Configuration」：米白底爆炸视图耳机，右侧材质选项与价格 |
| 约 12–14s | 技术图谱：深蓝底节点网络（GraphQL、Rust、WebGPU 等），左侧分类筛选 |
| 约 14–16s | 物流数据看板「Network Operations Overview」：白底 KPI 卡（$1.76M、96.4% 等）与折线、柱状图 |

## 画面构成：每段都是「全屏主画面 + 半透明 UI 面板」

每个 demo 都按真实网页应用录屏呈现：主视觉占满画面，四角或侧栏叠加小号 HUD / 控件面板。游戏类把分数、血条放在左上和右上角；工具类用左栏或右栏放控件、正文区放主体。合集本身没有统一片头字幕，靠 demo 内容自身的差异形成节奏。

## 配色：前半深色霓虹，后半转向浅色产品界面

前 5 段以深色为底（接近 #0a0812、#2d1929），点缀霓虹粉、青色和落日橙；第 6 段起切到米白底（耳机配置器）和白底看板，强调色变成墨绿柱与青绿折线。palette 中的 #5f4646、#837b7b 是峡谷与夜景段的暖灰中间调。

## 叙事顺序与节奏：等长硬切，类型从游戏到工具

可见的 8 段长度都约 2 秒，段间直接硬切，不加转场效果。顺序是「游戏 → 模拟 → 产品配置 → 数据工具」，由娱乐感逐步过渡到实用感，最后停在信息密度最高的看板上。注：标题称 17 个 demo，截帧只看到 8 段，其余段落是否存在、时长多少无法从截帧确认。

## 内容替换

- 每段 demo 可整体替换为自己的作品录屏或网页截图动画；保留「每段约 2 秒、硬切、主画面全屏 + 角落 UI」的结构。
- 品牌和文案（SOLARIS、Bespoke Configuration、Network Operations Overview 等）都属于 demo 内部内容，替换时换成自家产品名即可。
- 建议保持「深色娱乐类在前、浅色工具类在后」的顺序，让收尾落在最有信息量的画面。

## 复刻注意

- 素材需求：8～17 段网页或应用的录屏（每段至少 2 秒稳定画面），统一 1280×720 输出。
- 难点：原片每段本身是完整可交互的 3D 游戏 / 模拟，从零复刻需要分别开发；做合集时直接用录屏素材最省事。
- `code` 为 false：原片是录屏剪辑，不适合用代码一次性重建；剪辑部分可用任意时间轴工具完成。

## 验收要点

1. 每段时长约 2 秒，段间为硬切，无黑场或淡入淡出。
2. 至少出现游戏、模拟、产品配置、数据看板四种类型。
3. 每段都有清晰的 UI 面板（分数、参数或 KPI），能看出是可交互应用而不是静态图。
4. 末段为浅色数据看板，KPI 数字可读。
