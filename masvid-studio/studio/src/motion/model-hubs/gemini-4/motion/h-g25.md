## 宽银幕 + 底部 HUD，场景按 3 秒节拍切换

画面上下留黑边，左上有小号章节名（如「// NEURAL GENESIS」），左下有时间码与「120.0 BPM // 1080P HDR」样式信息，右下有小型音频频谱条。场景约每 3 秒切一次，部分场景跨两句标语，切换为光效闪白或推进式过渡。

## 冷蓝底，紫粉与暖金做高潮

基底是深蓝（#02050b、#142c50、#21436e、#386690）；中段霓虹隧道和光环转为青（约 #3ae0f0）+ 洋红紫（约 #c050f0）；鸟居段是粉紫晚霞配暖橙光球（约 #f0a050）；黑洞段为白金色吸积盘。结尾回到深蓝和一道横向蓝白光带。

## 日文主句 + 英文副句

每屏一句日文明朝体大字，白色带柔光，居中或上 / 下居中；下面一行宽字距英文小号大写作为译文。唯一例外是「光」单字特写，字号放大到画面高度约 1/4。章节名和 HUD 信息更小，不干扰主句。

## 内容替换

- 标语可换成任意品牌宣言或产品理念，每屏一句主句 + 一句译文。
- 场景可替换成其他抽象视觉（粒子、隧道、星球），保留每 3 秒一切、色调由冷到暖再回冷。
- 收尾标题换成品牌或作品名。

## 复刻注意

- 需要：多段抽象 3D / 着色器视觉（粒子螺旋、光线隧道、水面倒影、吸积盘、放射光环）。
- 难点：黑洞吸积盘、水面反射和霓虹隧道各需单独着色器验证；各场景风格统一需统一泛光和色调。
- code 为 true：可用 three.js / WebGL 着色器 + HTML 文字层逐场景重建。截帧无法确认原片是否卡音乐节拍，HUD 上的 BPM 字样仅作装饰参考。

## 验收要点

1. 每个场景都有一句日文主句和一行英文副句。
2. 场景切换节奏约 3 秒一次，全片 7～8 个场景。
3. 宽银幕黑边和底部 HUD 全片一致。
4. 结尾为「創世の律動 / PULSE OF GENESIS」标题。
