## 中央一张纸卡舞台，右边一栏史料

页面顶部是标题栏（「China History Sketch」、Remix、Device 按钮），下方导航「剧场舞台 / 朝代快选 / 配乐工坊 / 历史群聊」和红色「暂停旋律」按钮。主标题「一笔画华夏：五千年历史轻松看」下方左侧是舞台：米色纸卡，红色印章角标（如「文明起源」「吉金甲骨」「百家争鸣」），幕名居中，黑色线稿火柴人与道具（火堆、甲骨、鼎、车轮），人物头上是圆角对话气泡，底部一条黑底白字字幕条。舞台下方是播放控制（暂停动画与配乐、倍速 1x / 1.5x / 2x、手绘抖动开关、「第一拍 / 第二拍 / 第三拍」分段）。右栏是本幕史料卡与「历史群聊」。

## 米白纸 + 黑线稿 + 中国红

- 页面底 #f7f7f9，纸卡米色 约 #f3ead8，边框浅灰 #bbb6b7。
- 线稿与正文黑 约 #1a1a1a；强调红 约 #c0302a 用于印章、按钮、火焰与关键标注。
- 字幕条黑底白字；少量绿色（人物或植物点缀）。

## 文字层级：页面主标题 > 幕名 > 气泡与字幕 > 史料小字

- 页面主标题「一笔画华夏：五千年历史轻松看」为大号粗体衬线中文。
- 幕名「第1幕 · 远古与三皇五帝」「第2幕 · 夏商周青铜时代」「第3幕 · 春秋战国」居中于纸卡上方。
- 对话气泡为中等字号白底黑字（如「卜问：今日下雨否？」「龟甲裂纹显示：下午有阵雨！」）。
- 右栏标题如「钻木取火与神农试毒日记」「甲骨文占卜与八百诸侯大联欢」「稷下学宫：诸子百家学术辩论赛」，正文为小号中文。

## 节奏：每幕约 10s，幕内按拍换对白

每幕内气泡与字幕按「第一拍 / 第二拍 / 第三拍」更换，人物有轻微手绘抖动和简单动作（举手、点火）。换幕时纸卡内容整体切换，右栏同步换卡，页面框架不动。顶部进度显示「第 1 / 12 幕」等，说明全片只录到前 3 幕。

## 内容替换

- 历史主题可换成任何时间线知识（公司发展史、科技史、某个城市的历史），保留「一幕一时期 + 线稿小剧场 + 对话气泡 + 史料侧栏」。
- 印章角标、幕名、气泡与字幕文案全部可替换。
- 线稿人物可换成品牌角色，建议保持单线黑稿风格。

## 复刻注意

- 素材：不需要外部素材，线稿用 SVG 绘制；史料文案需核实史实。
- `code` 为 false：参考片是交互网页录屏；但线稿、气泡、字幕都是矢量元素，复刻成视频时可用 SVG 动画直接做。
- 难点：手绘抖动（线条轻微随机偏移）与人物简单动作的节奏控制；中文排版在小字号下的可读性。

## 验收要点

1. 中央米色纸卡舞台，黑色线稿火柴人 + 对话气泡 + 底部黑字幕条。
2. 至少 3 幕，每幕有幕名与红色印章角标。
3. 气泡与字幕在幕内按拍更换。
4. 右栏史料卡与幕同步。
5. 页面主标题与播放控制栏全程可见。
