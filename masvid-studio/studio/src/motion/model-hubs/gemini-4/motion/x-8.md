## 画面构成：中心航线 + 四角 HUD

画面中轴是一条浅色河谷或跑道一直延伸向地平线，两侧是橙色低多边形峡谷壁，空中漂浮扁平的蘑菇状岩台。准星圆环始终在画面中心。左上角是「AERO CANYON」关卡名，右上角是「GATES 12/12、FLIGHT TIME、BEST」计时面板，左下是空速、高度、加力条，右下是一排按钮（Boost、View: Chase、Auto On、Restart 等）。

## 配色：暖橙峡谷对冷青 UI

峡谷主体是 #603320 一带的焦橙与锈红，阴影接近 #2a2d28，远景天空偏粉紫落日。所有 HUD 用深色半透明底、青色数字（如计时 00:15.25），唯一的强暖色按钮是橙色「Restart」和「Fly Again」。冷暖对比让 UI 在暖色场景中始终清楚。

## 叙事与节奏：重复穿环推进，成绩卡收尾

每约 1.1 秒穿过一个圆环，顶部「GATE 0X CLEARED — SURGE!」提示条随之刷新，这是全片唯一的节拍信号。约 7.5 秒有一次贴脸穿越大环，作为中段的视觉高点。结尾不切黑，直接在游戏画面上叠加成绩卡：金色小标签「GOLD WINGS」、大标题「Course Complete!」、三格成绩（FINAL TIME 00:15.25 / BEST TIME / AVG SPEED 486 KTS）和橙色按钮。

## 内容替换

- 关卡名（AERO CANYON）、成绩卡标题和数值、按钮文案都可以替换为自家游戏或品牌。
- 峡谷可换成城市、海面、太空等场景；保留「中轴航线 + 两侧壁 + 中心圆环」的构图。
- 成绩卡结构（标签 → 大标题 → 三格数据 → 一个主按钮）建议保留，换成活动结果或产品数据也成立。

## 复刻注意

- 需要一个实时 3D 场景（three.js 一类）：程序化峡谷地形、漂浮岩台、圆环与飞行相机。
- 难点：相机沿路径平滑飞行和穿环判定需要单独调；低多边形峡谷的光照与雾效要验证。
- `code` 为 false：原片是游戏实录；若只要视频效果，可用预设相机路径渲染代替真实操控。

## 验收要点

1. 相机始终沿中轴前进，中心有准星圆环。
2. 顶部关卡计数随穿环递增至 12/12。
3. 四角 HUD 完整：关卡名、计时、速度高度、按钮栏。
4. 结尾成绩卡出现时背景压暗，卡片含标签、标题、三格数据和主按钮。
