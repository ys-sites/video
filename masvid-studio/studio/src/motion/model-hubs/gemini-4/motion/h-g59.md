# 晚霞车站像素动画

一支 15 秒的方形像素风（用清晰可见的小方块像素绘制）循环画面：晚霞下的乡间小站，一节红褐色老式电车停在站台雨棚下，车窗亮着暖黄灯；电车向右缓缓驶出画面，站台上留下一个人的剪影，他抬手挥别，最后静静站在空站台上，身后是粉紫色积雨云和远山。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2.5s | 电车停站：一节红褐色单节车厢停在站台雨棚下，部分车窗亮灯，站台上一个人的黑色剪影站在车门旁 |
| 约 2.5–4s | 车厢所有窗户依次亮起暖黄灯，车顶冒出一缕淡灰蒸汽，车尾红色尾灯亮起 |
| 约 4–9s | 电车向右平移驶出，人物剪影留在原地，雨棚与车厢逐渐错开，左侧路灯与灌木露出 |
| 约 9–11s | 车厢只剩右边缘一截，人物抬起右手挥别，车尾红灯在画面右边缘闪过 |
| 约 11–15s | 空站台：人物放下手静立，远山、积雨云、电线杆和前景麦浪仍在轻微摆动，可首尾循环 |

## 画面构成：上大天空、下窄站台的三层横构图

画面上约 55% 是天空和巨大的积雨云，中间一条细窄带是站台、雨棚、电车和远山，下约 25% 是深色前景草丛。雨棚在左中位置，屋顶是深蓝黑色平顶，下面一盏冷白灯管；左侧一盏亮着的老式路灯，右侧一根木电线杆，电线横贯画面。人物剪影极小，只占画面高度约 5%，靠位置和动作被注意到。

## 配色：深蓝天空 + 粉紫云 + 暖黄车窗

天空由上到下从深蓝 #2549a7 过渡到紫 #6a5aa0；积雨云高光是粉白 #f8cec4，暗部为粉紫 #c890c8。远山是灰紫蓝 #313456，站台与雨棚为近黑 #19151e。电车车身红褐 #7a3a2a，车窗暖黄 #f6d27a，尾灯红 #e83a4a。前景草丛为暗褐 #3a3228 带少量高光。

## 动作与节奏：一个画面只做一件事

全片镜头固定，唯一的大动作是电车从左往右匀速驶出（约 6～7 秒），其余都是小动作：车窗亮灯、蒸汽、尾灯闪、人物挥手、草丛与云的轻微飘动。节奏非常慢，适合作为循环壁纸或氛围画面；结尾空站台与开头构图一致（只差电车），便于做循环。

## 细节：小光源让画面有温度

车厢侧面中下部有一块小的蓝色铭牌，车顶有几个深色通风罩。雨棚下的灯管、左侧路灯和车窗是画面里仅有的三处人造光，都偏暖或冷白，与粉紫天空形成对比。电车离开后，雨棚下的站台边缘只剩灯管投下的一条浅色光带。

## 内容替换

- 电车可替换为公交、渡轮、飞机等交通工具，保留「停靠 → 亮灯 → 驶离 → 人物挥手 → 空景」的离别结构。
- 人物剪影可替换为品牌角色或宠物剪影，动作保持简单（站立、挥手）。
- 晚霞配色可换成清晨、夜晚或雪天版本，保持像素风格与三层横构图。
- 可在天空空白处加一句短文案（建议，原片无文字）。

## 复刻注意

- 素材需求：像素风站台、雨棚、电车车厢（含窗户亮灯两种状态）、人物剪影（站立 / 挥手两帧）、积雨云、远山、前景草丛。
- 难点：像素风要保持整数像素对齐，平移时避免发虚；云和草的轻微摆动需要逐帧或分层位移，单独验证。
- `code` 为 true：可用 Canvas 按分层贴图重建，关闭图像平滑，电车用逐像素平移，人物用两帧切换。

## 验收要点

1. 1:1 方形画面，上方大面积深蓝天空与粉紫积雨云。
2. 红褐色电车停在雨棚下，车窗亮起暖黄灯，随后向右驶出。
3. 站台上人物剪影在电车离开时抬手挥别。
4. 结尾为空站台静景，可与开头无缝循环。
5. 全片保持像素风格，没有文字。
