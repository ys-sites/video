# PageOn 软件发布与界面展示

一支浅色极简的软件宣传短片：大标题开场，接着展示输入提示词的对话框、生成的演示稿缩略图，再横向浏览几种视觉风格的封面，最后以 PAGEON 标志和标语收尾。

- 唯一 ID：h-g19
- 原帖：https://www.iart.ai/blog/gemini-4-animation-prompts
- 作者：iArt
- 生成模型：Gemini 4 Argon
- 尺寸 / 比例：1280×720（16:9）
- 时长：约 18.05s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2.5s | 开场标题「An idea deserves a stage.」左对齐两行 |
| 约 2.5–7s | 「Start with a thought.」+ 白色输入框，内含提示词「Create a presentation about urban gardens. Clear ideas, bold visual storytelling.」 |
| 约 7–9s | 输入框上移变淡，下方浮出生成结果卡「AuraStrat」 |
| 约 9–13s | 「Explore visual styles」：横向滑过多张封面（青绿渐变、「Deep Resonance.」深灰圆环、「RESEARCH & ANALYSIS 01.」黑底） |
| 约 13–18.05s | 收尾：PAGEON 标志，「Make your ideas visual.」，胶囊「pageon.ai」 |

## 每屏一句小标题 + 一个界面元素

除开场和结尾，每屏左上都有一个带绿点的小标题（Start with a thought. / Explore visual styles），下面放一个主元素（输入框或封面卡）。顶部居中一条短绿线和细框线作为固定版式锚点，画面像一张持续翻页的浅色幻灯片。

## 米白底、细绿线、黑字

背景米白（#f1ede2），细分隔线浅灰（#b9bab1），文字近黑（约 #1a1a1a），唯一强调色是薄荷绿（约 #3aa57a）的小圆点和短线。封面卡是唯一出现强对比的地方：深灰、纯黑和青绿渐变，标题「Resonance.」用粉蓝渐变字。

## 文字层级

最大字是开场「An idea deserves a stage.」和结尾「Make your ideas visual.」，粗体无衬线；小标题中号；输入框内提示词和网址胶囊最小。叙事顺序是「主张 → 输入 → 生成 → 多风格 → 品牌」，转场以淡入淡出和整体平移为主。

## 内容替换

- 品牌名、标志、网址、标语可替换为任意 SaaS 产品。
- 输入框提示词和生成结果卡可换成自家产品的真实界面截图。
- 风格封面可换成作品集或模板缩略图，保留横向滑动浏览。

## 复刻注意

- 需要：产品标志、3～4 张作品封面图、一个输入框界面截图或 HTML 重建。
- 难点：低，主要是版式与留白控制；封面横滑的速度和遮挡要统一。
- code 为 true：全片可用 HTML/CSS 动画代码直接重建。

## 验收要点

1. 开场和结尾各一句大标题，中间每屏一个小标题。
2. 输入框内的提示词完整可读。
3. 至少横滑展示三种不同风格的封面。
4. 结尾标志、标语、网址三层垂直居中排列。
