## 统一的蓝色渐变舞台承载每一步

所有画面都放在同一块深蓝到亮蓝的渐变底（#091a47 → 约 #1f5fd0）上，顶部居中小字「Gemini 4 Argon」作为常驻标识，底部居中白色字幕。中间内容按步骤换成桌面窗口、单个图标、对话面板、幻灯片页面，像一张始终不变的展台。

## 成品页用红、米白、深色三种底

演示稿页面是叙事高潮：封面整页红橙（约 #e8492e）配大号白字和右侧沙色照片；内页米白（#ededea）配深色细线表格和红色关键数字（「14.4×」「~350 W」）；流向图里红、粉、青三色分支。外围舞台的蓝和页面的红形成冷暖对比。

## 文字层级：字幕讲故事，页面大字给结论

旁白式字幕是第一人称陈述，一次一到两行，小号白字。页面里最大的字是「Flight in thin air」「Cryogenic drain」这类标题，其次是红色数字指标，表格与说明为极小字只作质感。结尾字标为白色中号无衬线加四角星图标。

## 内容替换

- 数据来源（NASA 火星）、文件数量（80,000）、成品主题可换成任何「杂乱原始数据 → 结构化演示稿」的故事。
- 字幕文案可重写，保留「问题 → 工具 → 输入 → 成品 → 品牌」五步。
- 成品页可换成自家模板截图，保持每页一个大标题 + 一个关键数字。

## 复刻注意

- 需要：桌面文件窗口素材（录屏或重绘）、ZIP 图标、对话面板截图、3～4 页成品幻灯片、火星 / 直升机图片素材。
- 难点：开场大量窗口的堆叠与收拢动画需要逐层排布；成品页内的数据图要真实可读才有说服力。
- code 为 true：舞台、字幕、窗口卡片移动和收尾字标可用 HTML/CSS 动画代码重建；页面内容建议用真实成品截图。

## 验收要点

1. 蓝色渐变舞台与顶部小标识全片一致。
2. 每段只有一句字幕，与画面步骤对应。
3. 窗口收拢成单个数据包图标的转折清楚可见。
4. 至少展示封面 + 两张带关键数字的内页。
5. 结尾为居中品牌字标。
