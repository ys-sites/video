# 粒子星系与 DNA 变形

一支无文字的粒子变形片：数十万发光粒子先组成旋转的螺旋星系，再收缩成球体，展开成交织的环带，变成双螺旋 DNA，最后散回远处的小星系，全程在深蓝夜空中连续变形。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 11s | 星系：斜视角螺旋星系，中心白粉色核心，外圈青紫粒子盘缓慢旋转 |
| 约 11–17s | 收拢：镜头推近，粒子向中心聚成密集的粉白团 |
| 约 17–22s | 球体：粒子成为边缘发亮的空心球，外缘青蓝、内部粉紫 |
| 约 22–33s | 环带：粒子拉成多条交织的粗环带，金黄与紫色混合，镜头贴近 |
| 约 33–39s | DNA：环带重组为青色与粉色两条螺旋链，背景散布星点 |
| 约 39–45.06s | 回归：粒子散开，远处只剩一个小而亮的星系核 |

## 一团粒子连续变形，没有剪辑

全片是一个连续镜头，所有形态都由同一批粒子重新排列而成，过渡时能看到粒子从旧形态流向新形态。镜头随形态大小推拉：星系和结尾是远景，球体和环带是近景，DNA 为中景竖向构图。

## 深夜蓝底，粒子分冷暖两组

背景近黑深蓝（#040a1d、#1b2345），带少量星点。粒子分两组颜色：冷色青蓝（约 #5ad0f0）与紫（#675f7a 偏亮的约 #b080e0），暖色粉白与金黄（约 #f0d0a0）。星系与球体中心最亮接近白色，加法混合形成泛光。

## 阅读节奏靠形态切换

画面没有任何文字；每种形态停留 5～11 秒，观众靠「认出形状」获得节奏点：星系 → 球 → 环 → DNA → 星系，首尾呼应形成循环感。

## 内容替换

- 目标形态可替换成任意可采样成点云的形状（Logo、产品轮廓、文字），保留「宇宙起点 → 若干形态 → 回到起点」。
- 粒子配色可换成品牌色，保持冷暖两组对比。
- 可在结尾形态加入品牌 Logo 作为落点（建议）。

## 复刻注意

- 需要：GPU 粒子系统（three.js Points / WebGL），每个形态的目标点位数组。
- 难点：数十万粒子在形态间的插值与噪声扰动需着色器实现；泛光和加法混合影响最终质感，要单独验证性能。
- code 为 true：可用代码直接重建，每段形态由数学函数（螺旋、球面、扭结环、双螺旋）生成目标点。

## 验收要点

1. 全片无剪辑，形态之间能看到粒子流动过渡。
2. 至少依次出现星系、球体、环带、DNA 四种形态。
3. 粒子有冷暖两组颜色，中心有泛光。
4. 结尾回到小星系，与开头呼应。
