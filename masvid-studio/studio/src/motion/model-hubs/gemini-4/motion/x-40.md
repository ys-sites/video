# 按品牌规范给自己做发布预告片

一支模型发布预告片：深蓝底上用滚轮式切换的一句话开场，随后以圆角卡片轮播展示用 Gemini 4 Argon 做出的 3D 作品（赛车、街机、海岛、星球、宝塔），每张卡配一句能力标语，最后回到一句收束文案和品牌字标。

## 卡片轮播，旁边露出下一张

作品以大圆角卡片居中，占画面约 3/4 宽；左右边缘露出相邻卡片的一角，底部有分页点，像横向滑动的轮播。每张卡左下角是一行小号提示词胶囊（如「Build a miniature 3D glass terrarium with living ecosystems」）和一行白色标题。

## 深蓝夜色底，彩色只在卡片里

背景是深海军蓝（#0a1d40）到稍亮蓝（#31475c）的渐变，带细微星点；文字白色（#f2f3f4）和灰（#808f92）。所有饱和色都来自作品卡：赛道洋红、街机粉黑、海岛青蓝沙色、宝塔暖木色。收尾页切到明亮蓝渐变（约 #1a5ce0），与前面暗底形成落点。

## 一屏一句话

全片文字层级只有三档：居中中号白字标语（开场和收束，收束第二行用蓝色强调「what will you bring to」）；卡片标题白色小号；提示词胶囊最小。开场滚轮文字以纵向滚动替换，前后行透明度降低。

## 内容替换

- 作品卡片可换成任意产品的案例截图或录屏，每张配一句能力标语，保留轮播布局。
- 开场滚轮里的三句「输入」示例和收束句可重写。
- 收尾字标换成自己的产品名；采集备注称原片文案由模型按品牌规范生成，复刻时可按自有品牌规范改写。

## 复刻注意

- 需要：5 段作品录屏或渲染（3D 游戏、街机、海岛、星球、宝塔）、品牌字标、图标。
- 难点：卡片内素材是真实 3D 作品，需另外制作或录制；卡片轮播的视差与虚化需逐层排布。
- code 为 true：采集备注称用 HyperFrames 制作，舞台、滚轮文字、卡片轮播和字标动画都可用 HTML 代码重建，卡片内嵌视频素材。

## 验收要点

1. 开场滚轮文字当前行清晰、上下行半透明。
2. 每张卡片同时有作品画面、提示词胶囊和标题。
3. 卡片两侧露出相邻卡片，底部分页点随卡切换。
4. 结尾由收束句过渡到亮蓝底品牌字标。
