# 275 个零件的参数化爆炸图

一支 CAD 工具的生成过程录屏：左侧对话面板里模型先问清结构方案，再按待办清单逐项执行建模操作，右侧 3D 预览从空白长出一台手机外壳、加上摄像头模组，最后展开成 275 个零件的爆炸图。

- 唯一 ID：x-24
- 原帖：https://x.com/extrudeai/status/2110255704431104051
- 作者：@extrudeai
- 生成模型：Gemini 4 Argon
- 尺寸 / 比例：832×480（约 16:9）
- 时长：约 107.72s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 12s | 提问：左侧出现选择题「How should the CNC aluminum midframe partition…」，四个选项；右侧空白「Preview updates once there is a sketch or solid to show.」 |
| 约 12–28s | 规划：左侧列出 TODOS 清单（约 15 项，如 Build CNC Aluminum Midframe…），右侧显示「Building…」 |
| 约 28–45s | 建模：左侧滚动 create_sketch / feature_extrude 等操作记录，右侧出现手机中框线框 |
| 约 45–60s | 成形：手机机身实体出现，清单推进到摄像头模组 |
| 约 60–90s | 细节：背面三摄模组成形，持续操作日志与干涉检查 |
| 约 90–107.72s | 收尾：assembly_placement 批量执行，右侧展开爆炸图，左上标注「275 objects」 |

## 左日志右模型，进度靠滚动清单表达

界面是固定两栏：左栏约 1/3 宽为对话与操作日志，底部输入框「Describe a part, request a change, or ask a question…」和模型选择「Gemini 4 Argon」；右栏为 3D 视口，底部视图按钮（Iso / Front / Top / Right / Fit / Wireframe），右下 XYZ 坐标轴小部件，顶部一行状态提示（「Showing the last finished model. Working on: …」）。镜头不动，变化全来自日志滚动和模型逐步出现。

## 深灰界面，模型是唯一的浅色体

背景近黑灰（#101113），面板与分隔线深灰（#4b4e53），日志文字浅灰，完成项前有绿色勾、当前项为黄色高亮。模型为浅灰哑光实体（约 #c9ccd1），发送按钮蓝色（约 #3b6cf0），坐标轴红绿蓝三色。

## 文字层级

最醒目的是开场问题的白色粗体句；其次是 TODOS 列表与当前进行项（黄色）；操作日志为小号等宽风格灰字，作为「正在工作」的质感；顶部状态行与「275 objects」为最小字。

## 内容替换

- 产品可换成任何可分件建模的硬件（耳机、相机、手柄），保留「提问 → 待办清单 → 逐步建模 → 爆炸图」。
- 问题与选项、TODO 文案、零件数量可替换。
- 界面品牌和模型名可替换，保持左日志右视口布局。

## 复刻注意

- 需要：真实 CAD 生成工具的录屏，或用 3D 软件分步做出中框、机身、摄像头、爆炸图四个状态 + 模拟日志 UI。
- 难点：爆炸图的零件拆分与沿轴向展开需要完整装配体；107 秒原速录屏节奏偏慢，建议加速中段。
- code 为 false：原片是工具录屏，建议录屏复刻；如用代码模拟，日志滚动和 UI 可用 HTML 重建，3D 模型需另备。

## 验收要点

1. 开场先出现结构问题和选项，右侧视口为空。
2. 清单项随进度逐个打勾，当前项高亮。
3. 模型按中框 → 机身 → 摄像头顺序出现。
4. 结尾为多层零件沿一个方向展开的爆炸图，并显示零件数量。
