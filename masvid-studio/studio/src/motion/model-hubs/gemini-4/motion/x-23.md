一支 35 秒的单 HTML 页面录屏：相机按水星、金星、地月、火星、木星、土星的顺序逐一巡游行星，每颗行星配左侧资料卡和底部一句解说，顶部固定标出所用提示词。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 5s | 水星（MERCURY）：灰白行星居中，远处可见其他行星和小行星带 |

| 约 31–35.3s | 土星（SATURN）：倾斜光环横跨画面下半部 |

## 画面构成：上方提示词条 + 下方网页应用

画面上约五分之一是白底黑字的提示词条：粗体标题「Gemini 4 Argon - One Shot」，下面两行完整提示词。下方是网页本身：左上「SOLARIS // 4K TOUR」标识，右上一排按钮（AUTO-TOUR ON、AUDIO OFF、ORBITS、SPEED、CINEMA MODE），左侧半透明资料卡（行星分类、名称大字、简介、距离 / 公转周期 / 直径 / 温度四格数据），底部一句解说字幕和行星导航栏。

## 配色：近黑宇宙 + 冷蓝星云

背景接近 #010205 的纯黑，叠加 #151c2d 到 #2e364c 的冷蓝星云带；行星本身提供全部暖色（金星米黄、火星橙红、木星褐白条纹）。UI 文字为白色和浅灰（约 #6f747e），当前行星在底部导航中高亮。

## 节奏：每颗行星 5～8 秒，资料卡随切换刷新

相机在相邻行星之间平滑飞行，资料卡和底部解说在到达新行星时替换。行星始终居中，相机环绕使受光面角度不断变化，形成「明 → 半明半暗」的光影变化。全片无转场黑场。

## 内容替换

- 行星可换成任何系列对象（产品线、城市、历史人物）；保留「相机逐一飞抵 → 资料卡刷新 → 底部一句话解说」的结构。
- 顶部提示词条可换成自家标题或去掉；资料卡的四格数据换成对象的关键指标。
- SOLARIS 品牌和按钮文案可替换。

## 复刻注意

- 素材需求：行星贴图（地表、云层、条纹、光环）与星空背景。
- 难点：真实感行星着色（大气辉光、明暗交界）和土星光环透明度需要单独验证；相机在行星间的路径要避免穿模。
- `code` 为 true：原帖称一次提示词生成单个 HTML 文件，可用 three.js 直接重建并录屏。

## 验收要点

1. 至少 6 颗行星按顺序出现，每颗居中停留 5 秒以上。
2. 左侧资料卡含名称大字、简介和四格数据，随行星切换刷新。
3. 底部有解说字幕和高亮当前行星的导航栏。
4. 土星光环、木星条纹清晰可辨。
