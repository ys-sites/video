# 彩色字母汇聚成 Logo

10 秒 3D 文字 Logo 演绎：彩虹色立体字「Wilming」站在反光地面上，字母先散落翻滚，被彩色光带卷起，再在一次粒子爆闪中重新排成整齐的 Logo。

- 作者：@wilming
- 生成模型：Gemini 4 Carbon
- 尺寸 / 比例：1280×720，16:9
- 时长：约 10.0s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 1s | 完整 Logo「Wilming」立在反光地面上 |
| 约 1–2.5s | 字母散开下坠、倾倒，W 底部滴落红色光点 |
| 约 2.5–5s | 彩色光带缠绕翻滚的字母，字母被卷到空中 |
| 约 5–6.5s | 字母回落归位，光带仍在穿绕 |
| 约 6.5–7.5s | Logo 背后一次金色粒子爆闪 |
| 约 7.5–10s | 余烬粒子飘落，一道白色光痕扫过 Logo，定格 |

## 黑色舞台上一排彩虹立体字

主体是一行粗圆体立体字，每个字母一种颜色，按彩虹顺序排列，带厚度和高光，下方是能映出字母倒影的黑色镜面地面。背景是深色空间，有几道斜向的微弱光束和散落星点。动态元素只有三种：字母本身、彩色丝带光带、金色粒子。

## 黑底 + 彩虹字母

- 背景 #1b1d22，地面反射暗灰 #565651。
- 字母颜色（左到右，观察）：W 红 约 #e03a4a、i 橙 约 #f08a2a、l 黄 约 #f0c82a、m 绿 约 #3ab84a、i 青 约 #2ab8e0、n 蓝 约 #3a6ae0、g 紫 约 #9a4ae0。
- 光带为同一彩虹色的半透明丝带；爆闪为暖金白色粒子。

## 文字层级：Logo 是唯一文字

全片只有「Wilming」一个词，大号粗圆体首字母大写，宽度约占画面 75%，没有任何其他字幕。

## 节奏：完整 → 打散 → 重组 → 爆闪定格

前 1s 先让观众读到 Logo，再打散；中段 4s 是光带与翻滚的混乱期；归位后用一次爆闪作为强拍，最后约 2.5s 让 Logo 稳定可读。镜头基本固定，只有轻微推近。无剪辑。

## 内容替换

- Logo 文字可换成任意品牌名（建议 5–9 个字母），保留「每字母一色」或换成品牌渐变。
- 光带颜色跟随字母颜色变化。
- 爆闪颜色可换成品牌主色。

## 复刻注意

- 素材：不需要外部素材，需要一个粗圆体字体做 3D 挤出（未提供原字体）。
- `code` 为 true：可用 three.js TextGeometry + 物理 / 关键帧动画 + 粒子直接重建。
- 难点：字母打散与归位要可控（建议关键帧而非真实物理）；丝带光带需要沿曲线生成带宽的半透明网格；镜面地面反射需验证。

## 验收要点

1. 开头和结尾都是完整可读的 Logo。
2. 每个字母颜色不同，按彩虹顺序。
3. 中段字母明显散开翻滚，并有彩色光带缠绕。
4. 归位后有一次粒子爆闪。
5. 地面映出字母倒影。
