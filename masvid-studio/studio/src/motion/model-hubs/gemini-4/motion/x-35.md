# 云朵做的猫追蝴蝶

一段 three.js 实时场景的录屏：一只由烟雾 / 体积粒子构成的黑色毛绒猫在纸白画面里追逐一只线条小蝴蝶，中段整个世界切到深蓝夜空模式，外圈出现符文环，最后回到白色画面。

- 尺寸 / 比例：1920×1080，16:9

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 4s | 白底，黑猫坐在中央大圆环前，烟雾在身边缓慢流动 |
| 约 4–5s | 短暂切到深蓝模式预览一次后回到白底 |
| 约 5–16s | 白底追逐：猫起身走动、扑向左右游走的线条蝴蝶，身后拖出灰色烟迹 |
| 约 16–30s | 深蓝夜空模式：背景变深蓝星空，蓝色云雾翻涌，圆环外出现一圈符文，猫在雾中穿行 |
| 约 30–40.3s | 回到白底，猫继续走动后停在中央，烟迹在四周散开 |

## 一只猫、一个大圆环、一缕烟

画面中央固定一个细线大圆环（像月亮或表盘），猫在圆环内外活动。猫没有清晰轮廓，是一团黑色毛绒状体积，边缘向外飘散成烟。小蝴蝶是一条白 / 灰色细线卷成的小符号，带拖尾，在画面中漂移。白底模式下地面散落细小的脚印状灰点。画面四角有极小的界面标记（左上小图标、右下圆形按钮）。

## 两种模式：纸白水墨 vs 深蓝星云

- 白底模式：背景近白 约 #f2f0ec，猫与烟为黑到灰（约 #0a0a0a → #9a9a9a），近似水墨在纸上晕开。
- 深蓝模式：背景 #020306、#0d1833，云雾 #192f60、#285099，亮部蓝 约 #3f7ae0；圆环为半透明蓝色，外圈符文为浅蓝小字形。
- 两种模式共享同一圆环和猫，只换底色和烟的颜色。

## 没有标题文字，只有符文与极小界面标记

正片没有说明文字。深蓝模式下圆环外围有一圈小号符文字符，作为装饰；四角界面标记极小，不承担信息。

## 节奏：慢速跟随，中段一次换天

猫的动作是连续的走、停、扑、回头，烟迹跟随延迟散开，整体节奏慢。白→蓝的切换是全片唯一的大转折，以整体淡变完成；约 4s 处有一次短暂预告。镜头固定，无剪辑。

## 内容替换

- 主角可换成其他动物或吉祥物，保留「体积烟雾构成的身体 + 边缘飘散」质感。
- 追逐对象（蝴蝶）可换成品牌小符号，保留细线拖尾。
- 两种模式的配色可换，建议保留「浅色水墨 ↔ 深色星云」的明暗对照。
- 圆环外的符文可换成品牌字母。

## 复刻注意

- 素材：不需要外部素材；猫的动作若来自动画数据需另备骨骼动画。
- `code` 为 true：原帖称用 three.js 实现，可代码重建。
- 难点：体积烟雾 / 粒子构成的毛发和流体拖尾、猫的行走与扑跳动作都需要单独验证，是复刻成本最高的部分。
- 建议先用固定路径做猫的移动，再叠流体烟迹。

## 验收要点

1. 猫由黑色体积烟雾构成，边缘明显飘散。
2. 中央细线大圆环全程存在。
3. 有一只带拖尾的线条小蝴蝶被追逐。
4. 中段切到深蓝星云模式，圆环外出现符文环，之后回到白底。
5. 镜头固定，节奏缓慢。
