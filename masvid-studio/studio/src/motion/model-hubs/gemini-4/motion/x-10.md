# 粒子光效秀

一个音频可视化网页「SONORA」的录屏：黑底中央是随节拍跳动的金紫色粒子圆环，下方控制面板切换粒子队形（Vortex、Burst 等）。

- 原帖：https://x.com/kimmonismus/status/2123168463518826561
- 作者：@kimmonismus
- 生成模型：Gemini 4 Neon
- 尺寸 / 比例：1280×720，16:9
- 时长：约 10.5s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 1.5s | VORTEX 队形：金色径向光丝环绕中心光点，外圈紫色拖尾旋转 |
| 约 1.5–4s | 切到 BURST：粒子向外炸开成星点云，圆环保留 |
| 约 4–6s | 回到 VORTEX，内环出现抖动的波形线 |
| 约 6–10.5s | VORTEX 持续，内环波形随节拍变形，外圈拖尾旋转 |

## 中心光点 + 放射环 + 外圈拖尾，三层同心结构

画面中上部是可视化主体：最内是一颗橙色发光核心，外面一圈细金线圆环，再外是放射状的短光丝，最外层是紫色和金色的螺旋粒子拖尾。主体下方占画面约 1/3 是半透明深色控制面板，左上角是标题，右上角是状态读数。

## 黑底上的金橙与紫色发光

- 背景 #08070b，暗部带一点暖褐 #3f2d2c。
- 粒子主色金橙 约 #f2a23a，核心高光 约 #ffd08a，外圈紫色 约 #7a4bd6。
- UI：面板深灰半透明，选中按钮为橙红描边（约 #e2553a），频段条 SUB 橙、MID 黄、AIR 紫。

## 文字层级：左上标题最大，其余全是界面读数

- 左上：小号「09 // ACOUSTIC FIELD」，下面大号宽字距大写「SONORA」。
- 右上：SOURCE SYNTH ACTIVE、ENERGY 百分比、TEMPO 116 BPM、FPS 60，以及 HUD 按钮。
- 面板：PAUSE AUDIO 按钮、频谱柱、SUB/MID/AIR 条、FORMATION（VORTEX / CYMATIC / BURST / RIBBON）、SYNTH PATCH & INPUT（Subharmonic Pulse (116 BPM)）、MIC、FILE、Particles / Reactivity / Trails / Synth BPM 滑杆，底部一行操作提示（Move pointer to bend field · Hold click for radial pulse · Space Play/Pause · 1–4 Formations · H Hide HUD）。
- 标题和数字使用等宽字形。

## 节奏：跟着节拍呼吸，切队形是唯一转折

镜头固定，主体持续旋转，粒子亮度和半径随能量值起伏（ENERGY 读数在 49%–69% 间跳动）。BURST 段是全片最散的画面，回到 VORTEX 后内环出现不规则波形线，作为第二个看点。无转场。

## 内容替换

- 标题「SONORA」与编号可换成任意作品名，保留左上「编号 // 类别 + 大标题」格式。
- 配色可换成其他双色发光组合，保留黑底与「暖色核心 + 冷色外圈」。
- 队形名、音色名、BPM 可换，保留下方控制面板结构。

## 复刻注意

- 素材：无需外部素材；声音驱动可用合成器或预置音轨的频谱数据。
- `code` 为 true：可用 Canvas / WebGL 粒子 + Web Audio 分析器直接重建。
- 难点：上千粒子的拖尾与加法混合发光要验证性能；导出视频时建议把能量曲线写死，避免画面不可复现。

## 验收要点

1. 黑底中央有发光核心、细金圆环、放射光丝、紫色外圈拖尾四层。
2. 约 2–4s 出现 BURST 星点外扩画面，之后回到 VORTEX。
3. 粒子大小或亮度随节拍起伏，不是匀速旋转。
4. 左上 SONORA 标题、右上读数、下方控制面板齐全。
5. 镜头固定，无转场。
