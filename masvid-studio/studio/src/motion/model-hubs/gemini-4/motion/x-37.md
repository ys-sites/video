# 机械眼眨眼后拆成零件

## 白展台中心构图，零件向四周炸开

产品始终在画面中心，背景是浅灰无缝展台（#d2d3d7 → #eaebee），地面柔和投影。爆炸方向以横向为主，镜片向左、线缆和齿轮向右，弧片绕球心散成放射状，展开后的占画面约 2/3 宽，再收回。

## 黑白主体加三处点色

主体是黑白棋盘式弧片和银色金属，点缀色只有三种：金色齿轮（约 #c8a040）、红色线缆（约 #c84a2a）、对焦时的蓝色虹膜（约 #3a7ad8）。外层录屏边框为紫色渐变壁纸（#b9b5cb、#605a79）。

## 外层文字是录屏装饰

画面顶部叠了一个深紫底白字大标题条「Gemini 4 Carbon」，以及上方「AI/ML API」标识、日期时间「28/10 18:26」；这些是录屏外框信息。产品页面内左上为「OCU-1 Robotic Eye」小标题和一行说明，右上三组小数字，底部居中两个切换按钮（类似 Replay / Assemble），零件标签为极小白底黑字。

## 内容替换

- 产品可换成任何可分件的硬件（相机、耳机、手表），保留「完整 → 炸开 + 标注 → 收回 → 亮点特写」。

## 复刻注意

- 需要：分件建模的 3D 产品（每个零件独立网格）、three.js 场景、零件标签 HTML 叠加。
- 难点：数十个零件的爆炸路径与回收要不穿插；弧片的放射散开需要按层计算位移。
- code 为 true：可用 three.js 代码直接重建爆炸 / 回收动画与标签。

## 验收要点

1. 开头和结尾都是完整产品，中段完全展开。
2. 展开时每个主要零件旁有名称标签。
3. 回收后零件准确合拢，无残留。
4. 结尾有一次明显的「对焦」亮点（蓝色虹膜）。
