## 两段同一套 HUD 语法，换的是世界

两款游戏都把信息压在四角：左上状态（WAVE / HOSTILES / SCORE 或 NULL INTEGRITY / BARREL ROLL / ACT I · OUTER GORGE），右上分数或雷达，左下生命条，右下武器与弹药或 SFX / PAUSE，底部居中一排按键提示（ESC Pause、R Reload、SHIFT Dash 等）。HUD 是细框半透明深色面板加青色进度条，读起来像同一套设计系统。

## 第一款暖橙，第二款紫青

竞技场：深蓝夜空（#0d0c16）、白色箱体（约 #f0d8c8）、橙色发光格栅与灯带（#dca782、约 #ff8a3a），红黑警示条纹。峡谷：紫粉晚霞天空、低多边形棕红岩壁（#4a2e31、#996557）、地面霓虹网格为青（约 #2ee6f0）与洋红（约 #ff4fd8）。

## 文字层级：分数最大，提示最小

最显眼的数字是弹药（如「09 / 120」）和分数（「001,100」「002,350」）；中号是生命值「100 / 88 / 72」；击杀提示（「AEGIS SENTINEL +440」「VESPID SCOUT」「STALKER DRONE +200」）以小号白字浮在准星附近；按键提示最小。
