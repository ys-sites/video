# 动画原则小角色动作演示

一支 3D 动画原则教学循环（网页预览录屏）：深灰舞台上一个红色方块小角色沿刻度轨道跳跃，左上清单依次点亮「ANTICIPATION / SQUASH & STRETCH / OVERLAPPING ACTION / FOLLOW-THROUGH / ARCS」五条原则，底部是播放控制面板。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 2.5s | 待机：角色蹲在轨道左端，聚光灯尚未打亮，清单全部未点亮，点击「Play Loop」 |
| 约 2.5–4.5s | 01 预备：灯光打亮，角色下蹲蓄力，第一条点亮为红色菱形 |
| 约 4.5–6s | 02 挤压拉伸：角色起跳时被拉长，镜头视角转向侧面 |
| 约 6–7.5s | 03 重叠动作：角色在空中翻转，附属部件滞后 |
| 约 7.5–9s | 04 跟随 + 05 弧线：红色虚线画出抛物线弧，五条全部点亮 |
| 约 9–11.6s | 落地复位：角色回到左端，清单重置为未点亮，循环 |

## 小舞台 + 清单 + 时间轴，三块各司其职

画面中央是一块倾斜的深灰平台（刻度轨道、台灯、黑色音箱、竖立小屏），角色在上面动作；左上是五条原则清单，当前演示到的原则前的空心菱形变实心红；底部深色面板显示帧数、进度条和按钮（Play Loop / 48kHz WAV / Mov Video）。镜头在演示中有轻微绕转和推近。

## 米白页面、深灰舞台、一种红

页面底为米白（#eeede8），舞台与控制面板为深炭灰（#302f2d），刻度与次要元素中灰（#9e9a96）。唯一强调色是红（约 #e0402a）：角色身体、清单点亮菱形、落点标记、弧线虚线和播放按钮。聚光灯在舞台上投出暖白圆形光斑。

## 清单是阅读主线

文字只有清单五行（等宽大写，编号 01–05，「&」为红色）和面板里的极小参数字。观众看角色动作的同时，用清单逐条点亮来确认「现在演示的是哪条原则」，最后全部点亮再一起熄灭，提示循环。

## 内容替换

- 原则清单可换成任何分步概念（产品功能五步、操作流程），每步对应角色一个动作。
- 角色可换成品牌吉祥物或产品模型；红色强调可换品牌色。
- 舞台道具（台灯、音箱）可替换为相关场景物。

## 复刻注意

- 需要：three.js 场景、一个可变形的简单角色、轨道与灯光、HTML 清单和控制面板。
- 难点：挤压拉伸与重叠动作要按动画原则手调关键帧，是本片质量的关键，需单独验证每个动作读得出来。
- code 为 true：场景、角色动画和 UI 都可用代码直接重建；网页外框（标题栏、Remix / Device 按钮）复刻时建议去掉。

## 验收要点

1. 清单五条依次点亮，与角色当前动作对应。
2. 起跳有明显下蹲预备，空中有拉伸，落地有挤压。
3. 跳跃轨迹显示为弧形虚线。
4. 结尾清单重置，角色回到起点可循环。
