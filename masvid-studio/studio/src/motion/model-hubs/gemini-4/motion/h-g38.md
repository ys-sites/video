# 木版画海岸夜景循环

一支约 10 秒的浮世绘风格循环动画：靛蓝月夜里，左侧亮灯的木造楼群、中间红色拱桥与远处富士山、右侧鸟居和松树，前景一艘挂红灯笼的小船在水面上轻轻漂移，水波和倒影持续晃动。

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 3s | 整幅夜景静态构图，小船从左侧缓缓向右漂，水面波纹与倒影晃动 |
| 约 3–5.5s | 小船漂到最右点附近，桥上灯笼与窗灯轻微闪烁 |
| 约 5.5–9.9s | 小船回漂向左，回到接近起点，形成可循环的首尾 |

## 固定机位，只有水和船在动

画面是单一固定机位的完整风景：上 1/3 是夜空与月亮，中部是岸线（左楼群、中桥与山、右鸟居松树），下 1/2 是海面。动的元素只有小船位置、船灯光点、水面白色波纹线、桥与窗灯的倒影竖条，以及月亮周围的云，适合做无缝循环。

## 靛蓝夜色配红灯和暖窗

主色是深靛蓝（#0d1e3a）与灰蓝（#374256、#69666a），海面同色系略深。暖色集中在三处：木楼窗格的暖黄（约 #f0b850）、红色拱桥与鸟居（约 #c8302a）、船头红灯笼（约 #e83a2a）。富士山顶白雪、月亮和水波线为米白（约 #f0ece0），远山后有一抹粉橙晚霞。

## 木版画式的平面造型

所有物体用平涂色块加细描边，水波是短促的白色曲线，倒影是竖向虚线条，属于浮世绘 / 木版画的平面语言；没有文字。

## 内容替换

- 地点可换成其他城市夜景（港口、古镇），保留「岸线横贯中部 + 前景一个移动小物 + 水面倒影」的构图。
- 小船可换成品牌物件或角色；灯笼颜色可换品牌强调色。
- 季节和时间（雪夜、黄昏）可换，保持一冷一暖对比。

## 复刻注意

- 需要：一张平面插画分层（天空、月亮、楼群、桥、山、树、海面、船），SVG 或分层位图。
- 难点：低；循环首尾对齐（船的位置与波纹相位）需要检查，倒影抖动可用正弦位移。
- code 为 true：可用 SVG + CSS / Canvas 动画直接重建。

## 验收要点

1. 机位全程不动，只有船、水波、倒影和灯光在动。
2. 首尾帧船位置接近，可无缝循环播放。
3. 红桥、鸟居、船灯三处红色与窗灯暖黄清楚可见。
4. 所有元素为平涂加描边的木版画风格。
