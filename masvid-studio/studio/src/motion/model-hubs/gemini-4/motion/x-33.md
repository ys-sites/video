# three.js 发光机械花

一支 45 秒的网页 3D 录屏：羊皮纸底的「机械花图鉴」页面里，半透明粉色机械花依次展示生长、爆炸分解、夜间发光等状态，切换三种虚构花卉，并有一只小蜜蜂在花间飞动。

- 作者：@thtbee_
- 生成模型：Gemini 4 Carbon
- 尺寸 / 比例：1920×1080，16:9
- 时长：44.54s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 6s | 第一种花「Paeonia machina」盛开，粉色多层花瓣、黄铜花茎，蜜蜂停在叶上 |
| 约 6–11s | 花朵收拢成小花苞，相机拉远 |
| 约 11–17s | 「EXPLODED」视图：花瓣、齿轮、线束分层散开，叠加圆形测量线 |
| 约 17–22s | 切到「NOCTURNE」夜间模式：星空黑底，花朵发出青白光，外圈一道光环 |
| 约 22–34s | 第二种花「Prunus escapement」：白色花苞与粉色小花，蜜蜂飞过，一段透视 X-RAY 状态 |
| 约 34–40s | 第三种花「Tulipa chronos」：白色郁金香底部露出金色齿轮 |
| 约 40–44.5s | 灰暗背景下 X 光风格：粉色花头 + 青蓝骨架茎 |

## 画面构成：图鉴卡片 + 中央标本

画面左侧固定一张米色图鉴卡：编号「NO. 01 / 07」、斜体衬线花名大字、红色小号副标（如 THE CLOCKWORK PEONY）、一段描述、四行带红色进度条的数据（PHOTON INTAKE、CORE ROTATION、NECTAR FLOW、BLOOM）。中央是 3D 花朵，周围散布手写体注释和细箭头。底部居中三个模式按钮（LIVING / EXPLODED / X-RAY），右上角「DAWN / NOCTURNE」切换，左上「Nectarlink」品牌名。

## 配色：羊皮纸米色上的半透明粉

日间段底色为暖米色纸张质感（目测约 #ece4d6），花瓣是半透明珊瑚粉，花茎黄铜金、叶片浅绿，数据条用暗红。夜间段切到 #030406 一带的星空黑，花朵变成青白辉光。palette 中的 #262020、#5f5451、#f4e6e0 分别对应暗部、灰褐文字与高光。

## 节奏：模式切换驱动，每态停 5～6 秒

画面没有硬切，变化来自页面内的状态切换：开合、爆炸、昼夜、透视、换花。每个状态停留约 5～6 秒，花朵持续缓慢旋转或呼吸，蜜蜂在花间穿梭提供小的动态焦点。

## 内容替换

- 三种花可换成任意系列产品或角色；保留「图鉴卡 + 中央 3D 标本 + 模式按钮」的展示框架。
- 卡片上的名称、副标、描述和四项数据可整体替换为产品参数。
- 品牌「Nectarlink」与模式按钮文案可换。

## 复刻注意

- 素材需求：可分解的花朵 3D 模型（花瓣、花蕊、齿轮、茎），纸张纹理贴图。
- 难点：半透明花瓣的层叠渲染、夜间辉光（bloom）与粒子、爆炸视图的零件位移、蜜蜂飞行路径都需要单独验证；原帖称耗时约 1 小时 43 分生成。
- `code` 为 true：three.js 可直接重建，模式切换用状态插值实现。

## 验收要点

1. 左侧图鉴卡元素完整：编号、斜体花名、副标、描述、四行数据条。
2. 至少出现盛开、爆炸分解、夜间发光三种状态。
3. 至少切换两种不同的花。
4. 有一只小蜜蜂在画面中移动。
