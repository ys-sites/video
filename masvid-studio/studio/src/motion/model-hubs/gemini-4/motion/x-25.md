# 合成波霓虹迷你高尔夫，agent 试玩

官方演示片：一句 prompt 让 Gemini 4 Neon 用 8 个并行 worker 做出合成波风 3D 迷你高尔夫「NEONPUTT '84」，再由 Antigravity 浏览器 agent 当 2 号玩家试玩；全片用左下角字幕逐段说明。

- 唯一 ID：x-25
- 原帖：https://x.com/antigravity/status/2123176067380711725
- 作者：@antigravity
- 生成模型：Gemini 4 Neon
- 尺寸 / 比例：1920×1080，16:9
- 时长：约 77.5s
- 资源状态：参考视频，无原工程

## 分段时间表

| 时间 | 段落 |
|---|---|
| 0–约 3s | 游戏画面冷开场：霓虹网格地面上的粉色与青色发光障碍 |
| 约 3–6s | 标题卡：「Gemini 4 Neon builds a 3D synthwave mini-golf game with Google Antigravity」 |
| 约 6–21s | 输入 prompt 并调用 /swarm，界面列出 8 个并行 worker 的分工 |
| 约 21–33s | Swarm Graph 节点图回放协调过程，8 个模块汇入 @engine 与 @verifier |
| 约 33–51s | 自动验证：构建、启动本地服务、打开内置浏览器试玩，8 个球场逐个验证 |
| 约 51–63s | Voice Mode 把 2 号玩家交给 Antigravity，线程内切换到 Gemini 4 Hydrogen |
| 约 63–72s | 真人打 1 号玩家，Antigravity 接手 2 号玩家瞄准击球 |
| 约 72–77.5s | 蓝色渐变尾卡「Gemini 4 Neon」 |

## 左边是 agent 对话，右边是游戏，一屏讲两件事

大部分时间是 Antigravity 应用的录屏：深色 IDE 风格界面，左侧是对话线程与执行日志，右侧是内置浏览器里运行的游戏。游戏是第三人称俯视的 3D 球场：黑紫背景、青色发光网格地面、粉紫色发光障碍、白色球洞与瞄准线。中段有一张节点连线图（coordinator 居中，shaders、physics、courses、scaffold、engine、verifier 等节点环绕）。

## 黑底 + 霓虹粉青，界面保持低调灰

- 背景近黑 #02020b，界面面板深灰 #2e2c45 一带。
- 游戏霓虹：青 约 #2fe0c8、品红 约 #e040c8、深紫 #220628，雾化蓝灰 #57757f。
- 字幕为白字，界面正文为浅灰小字；尾卡为蓝色渐变，白色无衬线字配四色星标。

## 文字层级：左下字幕是叙事主线

每段在左下角放一组两行字幕：上行白色中号主句，下行灰色小号补充。按顺序出现的主句有：「One prompt defines the game and invokes /swarm」「Gemini 4 Neon assigns 8 parallel workers」「8 specialized Gemini 4 Neon workers run in parallel」「Swarm Graph replays parallel coordination live」「All 8 modules converge into @engine and @verifier」「Self-verification steps run automatically」「Autonomous browser control tests the live game」「All 8 synthwave courses verified live」「Voice Mode assigns Player 2 to Antigravity」「Switch in-thread to Gemini 4 Hydrogen」「Human plays Player 1」「Antigravity takes over as Player 2」「Antigravity aims and takes the shot」。字幕左侧有一条竖向细线。开场标题卡为居中大号白字，下有三个小标签（8-worker /swarm、Autonomous browser verification、Live 2-player match）。

## 节奏：一条字幕一个动作，约 3–6s 换一次

每段字幕对应一个可见动作（输入、分配、连线、构建、试玩），字幕和画面同时切换。界面段之间多为直接切换或轻微推镜放大到关键区域；游戏段镜头沿球道移动。

## 内容替换

- 游戏可换成任意由 agent 生成的小应用，保留「prompt → 并行分工 → 节点图 → 自动验证 → 人机对战」五步。
- 字幕文案按新流程改写，保持「白色主句 + 灰色补充」两行格式。
- 霓虹配色可换，尾卡品牌可换。

## 复刻注意

- 素材：需要真实的 agent 工具录屏与游戏录屏；节点图、字幕、尾卡可以用代码重建。
- `code` 为 true：游戏本身（GLSL 着色器、物理、程序化音效）原帖称由代码生成，但复刻成视频时主要难点在录屏素材，不是动画。
- 难点：3D 球场的辉光、网格与物理击球要单独验证；节点图的连线高亮需要和字幕时间对齐。

## 验收要点

1. 开场有游戏冷开场 + 居中标题卡。
2. 每段都有左下两行字幕，顺序与流程一致。
3. 出现节点连线图，并有连线依次点亮。
4. 有真人与 agent 轮流击球的画面，界面标注 Player 1 / Player 2。
5. 最后约 5s 为蓝色渐变尾卡。
