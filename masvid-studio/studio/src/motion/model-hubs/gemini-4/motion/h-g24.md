# Gemini Argon 30 秒能力自我介绍

## 画面构成：中央主视觉 + 底部两行字幕 + 四周 HUD

每段中央是一个发光主体（线框、粒子、纽结、球体、星标），下方是两行字幕：大号粗体大写主句和小号副句。画面最底部有一条音频波形条，顶部一行等宽小字状态栏，四角有细角标框。中段的代码窗口与节点图以深色半透明面板呈现。

## 配色：深蓝星空 + 霓虹青、粉、红

底色为 #1a4361 到更深的蓝黑，带白色星点和散落的紫色小方块。主体发光色以青色为主（#206292 一带的蓝向亮青过渡），辅以粉红轨道；纽结段整体转为暗红色调，是全片唯一的暖色段。字幕多为白色或青色，纽结段字幕为橙红。

## 节奏：一段一句宣言，字幕驱动

每段 4～7 秒，主视觉切换伴随字幕整句替换，句子都是短促的第一人称宣言，层层递进到「I COMMAND THE MACHINE」，再落到品牌名与「YOUR MOVE.」。段间以主体消散 / 新主体出现衔接，节点图与代码段是逐行打字式出现。

## 内容替换

- 字幕宣言可换成任何产品的第一人称自述；保留「我是谁 → 我不是什么 → 我会什么 → 我能做到 → 品牌名」的递进。
- 四项能力标签和技术标签可换成自家卖点。
- 结尾字标与图标换成自家品牌，「YOUR MOVE.」可换成行动号召。

## 复刻注意

- 素材需求：品牌图标、等宽与粗体无衬线字体（原片字体名未知）。
- 难点：红色纽结是实时光线步进（raymarching）的 SDF 着色器，粒子旋涡和全息球也需单独验证效果与帧率。
- `code` 为 true：three.js / WebGL 着色器加 HTML 字幕层可直接重建。

## 验收要点

1. 至少 5 段，每段一个发光主视觉和一句两行字幕。
2. 出现代码窗口与节点图同屏的一段。
3. 出现四项能力标签卡的一段。
4. 结尾为品牌字标与行动号召文字。
