## 画面构成：一词一屏，中心构图 + 角标细节

每一屏只有一个主关键词，几乎都放在水平中线上，字号占画面宽度 40%～90%。主词旁配一个与词义相关的图形：SPATIAL DEPTH 配 3D 多边形球，FLUID 配缠绕曲线，TIMING 配转盘，DETAIL 配细线花瓣。画面四角和底边有极小的等宽字说明，如「CURVE // SPRING(…)」「REALTIME 3D PROJECTION // 60HZ」，用来营造「代码驱动」的工程感。MODULAR SYSTEMS 一段是唯一的多面板分屏，五个圆角卡片拼成网格。

## 配色：荧光绿当主角，红蓝白黑轮换做底

背景在四种底色间轮换：米白 #ecebe9、近黑 #141318 左右、正红约 #e5322b、深紫黑带紫色暗角。强调色固定三种：荧光绿约 #d4f53c、电光蓝约 #473ac3、正红；紫色 #8b3fd6 一带只出现在色柱和曲线里。palette 中的 #381619 是红底屏暗部，#cfd0c2 是米白卡片的灰阶。同一屏内最多同时出现三种饱和色。

## 文字层级：超粗宽体大字 + 等宽小字注释

主词全部是大写、超粗、字身很宽的无衬线字形，部分做成空心描边（SPATIAL DEPTH 背景字）或被图形遮挡一截（TYPE THAT MOVES 的 THAT 左侧被黑块切掉）。第二层是胶囊标签里的中号粗体（IN / EVERY / FRAME.）。第三层是很小的等宽说明字，常放在胶囊描边框里（「CRAFTED FRAME BY FRAME」「SHOWREEL 2026 // 100% REALTIME CODE」）。结尾副标题「ART DIRECTION · KINETIC SYSTEMS · 3D · SOUND DESIGN」字距很宽、灰色。

## 转场与节奏：约 1 秒一切，靠硬切和图形擦除

画面切换以硬切为主，中间穿插横条纹推移、碎片散开、粒子旋涡吸入等图形转场。前段每个关键词停留约 0.9～1.8 秒，9.3～11.3 秒突然加速到每 0.2 秒一词，形成全片最密的高潮，随后粒子旋涡和品牌卡放慢收尾。字的进场常用横向滑入、错位重复、弹性缩放；结尾 logo 圆环有旋转进场。整体是快节奏卡点展示，信息密度高、单屏信息少。

## 内容替换

- 关键词序列（KINETIC / FLUID / TIMING / DETAIL 等）可换成自家产品的能力词，保持「一词一屏 + 一个对应图形」。
- 结尾品牌卡「CLAUDE // MOTION」与 logo、服务列表、胶囊文案可直接替换为自家品牌；保留居中 logo → 大字 → 小字列表 → 胶囊的四层结构。
- 等宽小字注释可改成真实参数或版本号，增加可信感。
- 配色可换成品牌色，但建议保留「一个荧光强调色 + 两个饱和辅色 + 黑白底」的组合。

## 复刻注意

- 素材需求：无照片或视频素材，全部是文字、几何图形、粒子和简单 3D 多边形。
- 难点：SPATIAL DEPTH 的低多边形球碎裂成三角碎片环、FLUID 的多色曲线缠绕文字、流线粒子旋涡需要单独验证；其余可用 2D 动画完成。
- `code` 为 true：可用 HTML/CSS + Canvas 或 three.js 直接重建，每屏写成独立场景按时间轴串联。
- 原片结尾出现的是「CLAUDE // MOTION」字样，复刻时换成自家品牌，不要沿用他人品牌名。

## 验收要点

1. 前段关键词屏每屏约 1～2 秒，约 9～11 秒有一段 0.2 秒一词的快闪，主词居中且是超粗大写字。
2. 荧光绿在每屏都出现（字、胶囊或图形），底色在米白、黑、红、深紫之间轮换。
3. 有一段 3D 多边形物体旋转并碎裂的画面。
4. 有一段多面板网格分屏（曲线、环形表、等距方块、列表）。
5. 结尾是居中 logo + 品牌名 + 小字服务列表 + 荧光胶囊。
