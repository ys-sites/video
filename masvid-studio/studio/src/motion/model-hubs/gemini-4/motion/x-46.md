## 一屏一句，灰底与黑底交替

每个画面只承载一个信息块：一句话、一组三卡、一个数字或一组对比。叙述性句子放在灰底（约 #6a6a6a）上，数据和能力放在黑底（#121214）上，黑底常带深灰放射线背景，形成「讲道理 → 给证据」的交替节奏。

## 黑、灰、红三色，青色只标数据说明

主色为近黑 #121214、中灰与浅灰白文字（#b7bcbd），唯一强调色是正红（约 #c8102e），用于第三张卡、第三条能力、右半屏和收尾横幅——「重点永远是红的那一个」。青色（约 #2ee0e0）只出现在数字下方的英文 / 日文说明行。

## 文字层级：明朝大字 + 等宽小标签

主句是大号日文明朝体（衬线），短句常分两行错位排布；数字用粗体等宽，是全片最大字；英文小标签（ELEMENT 18 // …、MASTERY PRINCIPLE #01 // HOW TO PROMPT ARGON）为字距拉宽的粗体等宽大写，放在主句上方。日文能力条为粗体黑体。

## 内容替换

- 所有日文文案、数据（64,008、91.7%、63.0%）、基准名可换成任何产品的卖点和指标，保留「设问 → 三步 → 大数字 → 三条能力 → 对比数据 → 原则 → 品牌横幅」。
- 收尾横幅的产品名和印章字可替换。
- 语言可换成中文或英文，主句保持衬线大字。

## 复刻注意

- 需要：衬线（明朝类）和粗等宽两类字体、放射线背景、计数动画；采集备注称旁白由 Gemini TTS 生成（截帧无法验证音频）。
- 难点：大数字计数与旁白同步需要按音频时间轴卡点。
- code 为 true：全片为文字与几何图形，可用 HTML/CSS 动画直接重建；录屏外框（应用工具栏、底部按钮）复刻时建议去掉。

## 验收要点

1. 每屏只有一个信息块，灰底说理、黑底给数据交替出现。
2. 每组并列项中只有一个用红色高亮。
3. 大数字有计数动画，最终停在目标值。
4. 收尾为倾斜红色横幅 + 产品名。
