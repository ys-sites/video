## 中央一颗棱镜，信息都绕着它转

主体是画面中央的双锥多面体，各面是彩虹渐变（绿、青、紫、粉、黄），持续旋转。外围依次是：细刻度圆环（颜色随段落变化）、内圈小号代码标签（PATCHED [CWE-79] 等）、漂浮的白色粗体「4」字若干、外围散落的红色漏洞标签。底部是透视网格地平线。左上角是模型信息小字（MODEL // GEMINI 4 CARBON、ELEMENT: C (ATOMIC NO. 06)、PRICING: $2 / $10 (CACHED -95%)），右上角是四条带色条的跑分 HUD（AA INTELLIGENCE INDEX v5: 59 (#1)、SEC-BENCH PRO (DETECT): 88.2%、CWE-BENCH (AUTO-PATCH): 71.0%、EXPLOITGYM (VALIDATE): 54.8%）。

- 背景深灰蓝 约 #0c1418，地平线与雾气 #596b73、#7c9ca3。
- 棱镜彩虹面：绿 约 #6ae08a、青 约 #5ad0e8、紫 约 #9a6ae8、粉 约 #f06ab0、黄 约 #f0d06a。
- 段落色：开场青、安全段粉红（漏洞标签 约 #f04a7a）、高潮段品红紫底（约 #4a1a4a）、定价段金色光圈（约 #e8b84a）。
- 字幕白字带发光，英文小字颜色跟随段落色。

## 文字层级：日文字幕最大，HUD 与标签最小

- 最大：底部居中日文大字幕，每句一行，白色带辉光。
- 中号：漂浮的粗体「4」，大小不一。
- 小号：字幕下方的英文等宽说明（如「SEC-BENCH PRO 88.2% // VULNERABILITY DETECTED」「HIGHEST INTELLIGENCE AT $2 / $10 PER 1M TOKENS」）、左上模型信息、右上跑分 HUD、环绕的代码 / 漏洞标签。

## 节奏：一句字幕约 9s，淡入淡出换句

每句字幕停留约 9s，淡入后保持，再淡出换下一句；棱镜全程匀速旋转，光圈刻度随段落脉动，「4」字和标签持续漂浮。没有硬切，全片是一个连续镜头，靠颜色和字幕分段。

## 内容替换

- 字幕可换成任意语言的歌词或产品卖点，保留「一句一段 + 底部大字幕 + 英文小注」。
- 中央棱镜可换成品牌符号的 3D 版本，漂浮的「4」换成品牌数字或字母。
- 右上 HUD 指标、左上信息栏可换成自家数据（需核实）。
- 段落配色可换，保留「每段一个强调色」。

## 复刻注意

- 素材：不需要外部素材；若配音乐需另备（本说明不描述音乐内容）。
- `code` 为 true：可用 three.js（棱镜、网格地平线）+ HTML 叠层（字幕、HUD、标签）直接重建。
- 难点：棱镜的彩虹面渐变与辉光；大量漂浮标签的布局不与字幕重叠。
- 原片跑分与定价数字来自原作者，复刻时如替换为真实数据需核实来源。

## 验收要点

1. 中央彩虹多面体棱镜全程旋转，外围有刻度光圈。

3. 底部每段一句日文大字幕 + 英文小字，约 9s 一换。
4. 右上跑分 HUD 与左上模型信息常驻。
5. 至少三段不同强调色（青、粉红、品红紫或金）。
