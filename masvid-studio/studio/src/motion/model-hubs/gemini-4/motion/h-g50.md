# 方块角色剧情 MG 短片

一支约 32 秒的扁平 MG（图形动画）小剧场：夜晚卧室里，头戴小白花的方块角色在床头柜旁打盹，戴礼帽的方块角色推门进来，掏出一瓶香水；香水的绿色香气飘成想象泡泡，她想象自己变成粉色、戴蝴蝶结的样子，镜子里也映出闪亮的粉色自己；之后一段墨镜、皇冠、哭泣的情绪起伏，最后两个方块并排躺在床上入睡，月光照进窗。全片无文字。

## 画面构成：一个卧室布景 + 想象泡泡

主场景是固定机位的卧室侧视图：左门、中窗、右床，紫色椭圆地毯定住角色站位。角色都是长方体身体加四条短腿，用礼帽和小白花区分身份；表情只靠眼睛、嘴、腮红和头顶符号（z、感叹号、爱心、乌云、闪电、音符）。想象段用一个边缘不规则的紫色大泡泡把整个画面包住，泡泡里换成绿色光晕背景，明确区分「现实」和「想象」。

## 配色：深蓝紫夜色 + 暖橙角色

墙面深蓝 #28356a，地面与暗部 #33293c，地毯和想象泡泡是紫 #7a4fa0 一带。角色身体为暖橙棕 #c8643a，想象中的自己是粉 #e86fa8；台灯是全片最亮的暖黄光源。香气用薄荷绿 #8fd6b4 半透明带，皇冠与闪电为金黄 #f2c230。palette 中的 #ae929a 对应暖灰色调的阴影与地毯边缘。

## 叙事与节奏：靠符号与表情推动，每拍 2～4 秒

没有对白和字幕，情绪变化全部靠头顶符号和表情完成：瞌睡 → 吃惊 → 想象 → 委屈 → 心动 → 炫耀 → 得意 → 失落大哭 → 平静入睡。每个情绪拍子约 2～4 秒，场景在「卧室」和「紫色想象空间」之间来回切换，粉色斜条纹和暗场是主要转场。开头打瞌睡与结尾入睡首尾呼应。

## 内容替换

- 香水可替换为任意产品（礼物、护肤品、饮料），保留「拿出产品 → 想象变化 → 回到现实」的结构。
- 角色身份配件（礼帽、小白花）可换成品牌吉祥物特征，身体保持简单几何体以便做表情。
- 头顶符号系统可沿用，替代对白传达情绪。
- 结尾可加品牌名或产品名小字（建议，原片无文字）。

## 复刻注意

- 制作方式：此片由 Claude Desktop 配合 Gemini 4 Argon 完成，不是 Gemini 单独生成；复刻时预期需要多轮人工引导和修改。
- 素材需求：两个方块角色的多表情版本（眼睛、嘴、腮红变化）、卧室布景、镜子、香水瓶、皇冠、头顶符号图标。
- 难点：角色走路时四条腿的交替、想象泡泡的形变进出、香气带的流动需要单独验证；剧情镜头多，建议先写分镜。
- `code` 为 true：全部是扁平矢量图形，可用 SVG + JS 动画重建，角色做成可替换表情的组件。

## 验收要点

1. 主场景为雨夜卧室：门、带月亮的窗、台灯、床、紫色椭圆地毯。
2. 两个方块角色分别戴礼帽和小白花，表情至少有 5 种变化（瞌睡、惊讶、委屈、开心、大哭）。
3. 有紫色不规则泡泡包住的想象段，出现粉色蝴蝶结方块与绿色香气。
4. 有镜子映出不同样子的自己的一幕。
5. 结尾两个角色并排入睡，月光束照进窗。
