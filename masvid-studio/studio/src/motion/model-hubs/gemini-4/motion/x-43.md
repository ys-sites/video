一支 AI 生成应用的录屏：从任务输入框开始，Agent 生成一个财务数据应用「MONEY MAP」，随后逐页浏览深色看板——资金流桑基图、部门预算、Budget vs Actual 明细、供应商、异常、What-If 模拟。

## 侧边导航不动，一页一种图表

看板固定左侧导航（Money Flow、Budget vs Actual、Monthly Trends、Departments、Vendors、Anomalies、Year-End Forecast、What-If Simulator 等），右上「Demo Dataset」「Find Budget Leaks」按钮常驻。每页换一种主图：桑基、折线、表格、横条 + 气泡、列表、滑杆 + 柱图，录屏节奏约每 8 秒翻一页。

## 深色看板，绿色是主强调色

看板背景近黑蓝（#0c111a），卡片深灰（#2b3234），文字白 / 灰。强调色以薄荷绿（约 #3ee0a0）为主，用于条形图、滑杆和正向数字；红（约 #e84a4a）标超支与 High；橙黄标 Medium；桑基图使用多色。开头 Agent 界面为白底浅灰，和看板的深色形成「生成前 / 生成后」对比。

## 数字是视觉主角

每页顶部一排 KPI 卡，大号白色数字（$14.74M、$77.8M、$102.59M）是最大字；页面标题中号（「Vendors」「What-If Simulator」）；Vendors 页用大号叙述句「…grown more than 18% since Q1.」做标题；表格与标签为小字。

## 内容替换

- 公司名（MERIDIAN DYNAMICS INC.）、数据集、金额可替换为任意业务数据。
- 页面顺序可按自家看板模块重排，保留「输入需求 → 生成应用 → 逐页浏览」的叙事。
- 应用名「MONEY MAP」和标语可替换。

## 复刻注意

- 需要：一套可运行的数据看板（可用 mock 数据）+ Agent 生成界面录屏。
- 难点：桑基图、气泡散点等复杂图表需图表库实现；录屏中的鼠标路径需提前设计。
- code 为 true：看板与图表可用前端代码（如 React + 图表库）直接重建，再录屏。
- 采集备注写「投资组合分析」，画面实际是企业预算 / 供应商支出看板，复刻时以画面为准。

## 验收要点

1. 开头先出现 Agent 输入界面，再出现生成好的应用。
2. 左侧导航全程一致，当前页高亮。
3. 至少展示 5 种不同图表类型。
4. 每页顶部有大号 KPI 数字，超支 / 异常用红色标出。
