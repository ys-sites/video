# Mobile App Scenario

Design interactive iOS and Android mobile application prototypes as self-contained HTML/CSS/JS, previewed by default in a **390 × 844** mobile viewport inside OpenMotion Design Studio.

## Guidelines
- Design mobile-first for `390px` width with safe-area top/bottom spacing (`padding-top: 48px`, `padding-bottom: 84px`) and comfortable touch targets (`>= 44px`).
- Use clear mobile navigation patterns: compact top bar, scrollable card/list body, and a fixed bottom tab bar (`3–5` destinations) with interactive tab switching in vanilla JS.
- Keep typography crisp and legible on handheld screens; honor the selected Design System tokens (`tokens.css` / `DESIGN.md`) when attached.
- Use `openmotion_design_project` and `openmotion_design_edit` with revision checks to create and iterate; resolve user annotations via `openmotion_design_comments` after applying feedback.
