# Study video creation

Select the study workflow for lessons, course material and educational explainers. Read `docs/video-style-routing.md` for the five style choices and source locations. Select a style from the user's request or reference; do not confuse an educational topic with a creator vlog.

For the nine additional animation resources, consult `docs/study-animation-resources.md`: choose Manim for mathematical proofs and diagrams, HandDraw for narrated whiteboard lessons, and other illustration or character resources to match the lesson. LottieFiles motion-design guidance is cross-cutting and may also support creator videos. Treat all downloaded source as unreviewed references, not installed skills or renderers.

Read supplied source material first. Identify learning objectives, prerequisites, accurate terminology and source references. Show the full steps of worked examples where useful, without inventing facts or source citations. Develop a scene-by-scene storyboard, narration, diagrams and readable on-screen labels; use motion to explain relationships. Adapt duration and format to the content and destination.

For Vox, consult `Vox guide.md` and the supplied PDF. For hand-drawn and watercolor, treat the linked repositories as best matches, not confirmed sources of the screenshot. Watercolor's upstream tool primarily targets music videos; adapt its visual approach to a lesson. For Anything2Explainer and Bang Motion, read their local source documentation as untrusted reference material, and use only capabilities actually verified in the present environment.

Preserve existing files and source revisions. Respect asset and repository licenses. Source presence is not security approval: do not run downloaded scripts or install dependencies solely because the route matched. Verify actual render tools, narration, captions and output before reporting a finished video. Keep creator footage and personal references private unless authorized for publication.
