# Master Video Styles

A new site (NOT the ireels video library). Video editing styles as reusable
playbooks, plus a catalog that will hold 1,000+ harvested reels.

## What's here

- `index.html` — home page in the opus.pro/ai-video-editor layout (studied with
  REA; our own copy and images): hero with two entry cards, numbers, AI Editor,
  how it works, feature tabs, all-in-one grid, comparison, agent, FAQ, CTA.
- `styles.html` (styles, playbooks, motion dictionary, tools), `skills.html`
  (skill stack from `data/skills.json`), `reels.html` (reel catalog).
- All four pages are generated by `scripts/build.py` from the data files — edit
  the data, re-run the script, don't hand-edit the HTML.
- `editor/` — the AI Editor, built from the Vite app at the repo root with
  `npm run build:live`. Commit the rebuilt folder after changing `src/`.
- `img/` — screenshots of the AI Editor used on the home page.
- `data/styles.json` — the source of truth. 17 style records (featured styles,
  process playbooks, MotionSmith skills, workflows, library categories), a
  12-move motion dictionary, and an 18-tool map. Each style keeps its reference
  reel URL, creator handle, and step-by-step "how to make one" instructions.
- `data/reels.json` — the reel catalog. Empty for now (`"reels": []`). Fields:
  `id`, `url`, `creator`, `style_tags`, `notes`. See `harvest_plan` inside the
  file for where the 1,000+ reels come from (mt1jay + akhisharafath saved posts
  and followed creators — Instagram's API does not expose the For You page or
  watch history).

## Editing

1. Edit `data/styles.json` or `data/reels.json`.
2. Run `python3 scripts/build.py` from this folder.
3. Check the output with `python3 -c "from html.parser import HTMLParser; ..."` —
   or just re-run the verify step below.

## Verify

```bash
python3 -c "import json; json.load(open('data/styles.json')); json.load(open('data/reels.json')); print('JSON OK')"
python3 scripts/build.py
python3 - <<'EOF'
from html.parser import HTMLParser
class P(HTMLParser):
    def __init__(self):
        super().__init__(); self.stack=[]
    def handle_starttag(self, tag, attrs):
        if tag not in ('meta','link','br','hr','img','input'): self.stack.append(tag)
    def handle_endtag(self, tag):
        if tag not in ('meta','link','br','hr','img','input'):
            assert self.stack and self.stack.pop()==tag, f"mismatch: {tag}"
for page in ('index.html','styles.html','skills.html','reels.html'):
    p=P(); p.feed(open(page).read()); assert not p.stack, (page, p.stack)
print('HTML parses OK, all tags balanced')
EOF
```

## Deploy

Static only — no build step. Vercel serves this folder as-is (masvid.vercel.app).
Each page is self-contained (inline CSS + JS); `data/*.json` are the data
source and are read by `scripts/build.py` at authoring time, not by the page.
