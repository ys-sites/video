# Paper-Cutout Collage Animation — InVideo + Claude Workflow

Source: `InVideo_Claude_Paper_Cutout_Guide.pdf` (uploaded Nov 17, 2026).
Goal: documentary-style collage explainer with layered paper textures and an editable
video project, without manually animating every frame.

## The 7-step workflow

1. **Open InVideo MCP** — go to invideo.io, find the MCP/integrations page, look for the
   Claude connection option, review setup instructions.
2. **Connect Claude** — choose Claude, click Connect, sign in if prompted, review
   requested permissions and approve only if comfortable.
3. **Copy the agent setup prompt** — copy the setup prompt from the InVideo MCP page,
   paste into Claude, follow instructions to complete setup.
4. **Prepare references** — gather paper textures, cutout characters, newspaper
   clippings, backgrounds, examples of the desired look. Tell Claude which references
   matter most.
5. **Ask Claude to build the video** — use the copy-paste prompt below, replacing
   [YOUR TOPIC]. Specify story, visual style, aspect ratio, duration, narration, music.
6. **Generate and review** — let Claude attempt the workflow, answer clarifications.
   Generation may take time and may use account credits or plan limits.
7. **Edit and export** — open the project/editor link, check scene order, timing, text,
   visual consistency, voiceover, music, transitions before exporting.

## Suggested settings (short vertical video)

- Duration: about 30 seconds
- Aspect ratio: 9:16 (Reels, TikTok, Shorts)
- Visual style: paper-cutout collage, layered textures, subtle shadows
- Voiceover: documentary-style narration
- Music: subtle cinematic background music

## Copy-and-paste prompt

Create a cinematic paper-cutout collage explainer video about [YOUR TOPIC]. Use my
reference images to match the visual style: layered paper textures, cutout characters,
subtle shadows, and smooth collage-style animation. Build the project in InVideo Editor
as an editable timeline where supported, with separate visual layers, text, transitions,
and audio. Keep the pacing engaging, the visuals consistent, and the storytelling clear.
First outline the scenes, then create the video project and provide the editor link if
the workflow supports it, so I can review and refine it. Suggested format: 30 seconds,
9:16 vertical, documentary narration, and subtle cinematic background music. Ask me any
essential questions before proceeding.

## Troubleshooting

- Claude does not show InVideo: check Claude's connector settings and confirm the
  integration is available for the account.
- Connection fails: retry the official setup flow, check authorization completed.
- Results do not match references: specify which image controls texture, character
  design, palette, composition.
- No editable timeline or editor link: ask Claude what the connected workflow supports;
  native timeline creation may not be available to every account.
- Export looks unfinished: review timing, spelling, audio levels, transitions, final
  frame before publishing.
