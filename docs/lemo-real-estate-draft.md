## Recommended direction

Use **Urban Sketch · Pen & Wash** for an illustrative property introduction; if actual property images or plans are provided, use them as the source for the property's appearance. If no accurate visual source exists, any code-generated home or room must be clearly labelled as an illustration, not a photograph or faithful depiction of the listing. Do not invent architectural features, measurements, views, locations or amenities.

## Candidate prompt after security review

> Make a 30–45 second real-estate film for [verified address], featuring [verified feature 1], [verified feature 2] and [verified feature 3]. Use the supplied property photos or footage, preserve their truthfulness, and use an Urban Sketch · Pen & Wash inspired look where it fits the material. If no property visuals exist, label any code-drawn scenes as illustrative and avoid depicting unverified features. Use a warm narration in the language of the brief and minimal on-screen text. Include a price only when provided. Keep source materials and earlier renders intact; verify visuals, narration, timings and the final file before delivery. Save the project and outputs under `films/<listing-slug>/`.

## Other style directions

1. **Time-lapse Symphony:** real-footage and photography edit with rhythmic, cinematic time shifts; adapt the original music-led, no-narration approach if the user wants voice-over.
2. **Tilt-Shift Miniature:** high-angle miniature treatment for neighborhood context or a distinctive opener; avoid treating invented geometry as an accurate property model.
3. **Projection on White Model:** clean architectural model and projected information for a development or site overview; requires accurate model or plans, not a guessed floor plan.
4. **Swiss Motion Graphics:** precise grid-based typography for an opener or verified feature cards; combine with property visuals if the user wants a tour rather than a purely graphic film.
