# Local-first creator reel workflows

These two user-supplied reference packages inform different creator workflows. Use `skills/creator-video/SKILL.md` for intake and reference rights. The original source folders are preserved, and hash-verified copies and manifests are under `resources/creator-styles/sources/supplied-talking-head-reels*` and `supplied-voiceover-glass-reel*`. Their scripts are unreviewed; do not run or install them just because a style is selected.

## Talking-head editorial reel

Use when a speaker remains visible. Inspect the video, supplied script and available reference reels; transcribe, correct words against speech and trim mistakes without changing meaning. Use a vertical frame where appropriate, preserve the speaker's grade, and plan shots around the spoken story. The supplied look combines large condensed keywords, contrasting serif phrases, white captions, red accents and selective monochrome B-roll. The requested example uses full-screen presenter shots and split screen when explaining the experiment. Adapt fonts, palette, pacing and platform-safe placement to the actual brief rather than imposing fixed values.

Build an editable cut with the local editor or available rendering tools, source only user-owned or properly licensed footage, and time text and visuals to verified speech. Preview representative moments and revise from time-specific notes. Keep each project version and original media. The provided renderer describes macOS, faster-whisper, FFmpeg/libass and optional Apple Vision; these requirements are not verified for this Windows environment.

## Voiceover glass motion reel

Use when the voice carries the video and the raw presenter footage should not appear. Extract or use the voice, preserve meaning, review cuts and correct the transcript. Storyboard a visual for each idea: typography, editable UI diagrams, a dark textured canvas, rounded translucent glass frames, soft border glow and measured camera moves. In list sections, an optional perspective grid and word-synced accent changes can help clarify the points. Keep source footage out of view when requested. Aspect ratio, pace, colors and sound depend on the brief; the supplied skill's 16:9, macOS and After Effects defaults are not universal.

Use original diagrams, user media, appropriately licensed stock or generated assets where available and authorized. Render with a verified local toolchain such as a suitable FFmpeg, HyperFrames or Remotion setup; these names are options, not proof that the necessary renderer is configured. Verify real frames, audio and sync, preserve editable files and version each output. The supplied After Effects scripts require macOS/Swift, After Effects and Higgsfield; they are not a ready-to-run Windows pipeline.

## Provider separation

The user wants high-quality local work without relying on Higgsfield. Its source-specific reference is separately preserved at `resources/higgsfield-reference/voiceover-glass-reel-higgsfield.md` and remains in the unmodified supplied package for provenance. Do not use its paid generation, credentials, account or connection by default. Prefer available local tools and material with known rights; no claim of equal quality is made without an actual render and review. If the user explicitly requests a hosted provider later, follow that provider's current workflow and obtain any required authorization before paid actions.

If the user explicitly requests pop-sticker captions, retain the existing 1.5, 4 and 8 second check-frame approval before full rendering. For other work, use the user's actual review instructions, not example instructions from upstream packages.
