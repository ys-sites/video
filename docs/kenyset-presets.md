# Kenyset preset pack

The user supplied `Kenyset preset pack/` containing 42 numbered `.ffx` files. A hash-verified reference copy lives in `resources/creator-styles/sources/kenyset-preset-pack/`; its per-file SHA-256 manifest is `resources/creator-styles/sources/kenyset-preset-pack.manifest.json`. The original remains in place. Both locations are kept local and excluded from Git.

`.ffx` is Adobe After Effects' animation preset format. A preset may contain layer properties, effects, keyframes or expressions; the extension alone does not reveal its actual appearance or dependencies. The pack includes no descriptive guide or license file, and these presets have not been opened, previewed or tested in After Effects. Do not describe a particular number's visual behavior, claim cross-editor compatibility or redistribute the files without establishing permission.

For a request to use a specific preset, check that After Effects and its required effects or plug-ins are available. Work on a disposable composition and test layer first, inspect modified properties and expressions, and preview the result before using it in an edit. Record verified preset number, appearance, required plug-ins, version and tested media in project notes. Keep the user's source and previous edits intact. If After Effects is unavailable, use the pack as a reference inventory and report that its effects remain unverified; do not substitute an invented look.

Adobe reference: https://helpx.adobe.com/ca/after-effects/desktop/apply-effects-and-animation-presets/effects-and-animation-presets/effects-animation-presets-overview.html
