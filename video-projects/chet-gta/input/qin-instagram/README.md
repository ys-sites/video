# @qinacademy reels (user-saved)

Source: https://www.instagram.com/qinacademy/ (Instagram requires a login, so the user saves the videos here).

Drop each reel here as an .mp4 (a saved file or a screen recording). If you can, name it `YYYY-MM-DD_short-description.mp4`; any name works.
Recent videos feature Chet the most; Sobhi appears too.

What happens next: every file gets a contact sheet, a transcript (Whisper), cut and pacing metrics, and per-character notes (look, wardrobe, voice, catchphrases, energy, running jokes, the format's recurring bits). The findings go into `brainstorming.md` and the character bibles in `01-assets/characters/` and `02-voice/`.

These are private reference material for this campaign; the files stay local and are not committed to git.
